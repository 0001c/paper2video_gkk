## 续跑接口约定

- `GET /api/jobs/{id}/rerun-plan`：只读，返回可重做性、可复用性、覆盖范围与产物版本 token。
- 新前端确认后提交 `plan_token` 和明确的 `reuse_script`。版本已变化、原任务未结束或共享目录被使用时返回 409，不创建任务。
- 免费复用任务保存 `require_reuse_script=True`，透传到流水线 `--require_reuse_script True`。执行时若讲稿失效，停止而非自动重新调用模型。
- 选择重新生成时会覆盖讲稿，可能产生 API 费用；默认重做沿用原任务配置，不采用新建草稿。
- 不带预检 token 的旧 API 调用仍保留原有兼容行为。新前端的严格复用保证以带 token 的确认流程为边界。
- `script_validation.py` 从 `subtitle_cursor_prompt_gen.py` 提取原校验函数，规则不变，原模块仍导出同名函数，Web 预检不加载模型依赖。
- SSE 返回经过字段筛选的任务配置，不包含凭据与内部文件路径；缺失任务的命名错误帧会停止重连并显示错误。

## 使用

前端产物已输出到 `web/static`；后端修改需重启 Web 服务。服务重启前必须确认没有运行或排队任务，避免中断生成。浏览器刷新后可直接看到新界面。

浏览器不能恢复 File 对象；内容文件、人像及上传参考音频需要重新选择。文字草稿只存本机浏览器，可在高级设置中核对恢复内容。
