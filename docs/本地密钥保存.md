# 本地密钥保存

在“管理连接”中添加或编辑连接，填写 API Key，勾选 **将密钥加密保存到本机（重启后恢复）**，点击保存。新连接默认勾选本机保存；既有临时连接保持原来的选择，须显式开启。旧服务内存中的密钥不能由新服务取回，首次升级须重新输入一次。

Windows 后端使用当前账户的 DPAPI 加密整份连接记录，文件位于项目 `.local/credentials/model-connections.dpapi`。不写浏览器 localStorage、任务快照、Git 或明文临时文件；API 仅返回“密钥已配置”和是否本机保存，编辑框不会回显密钥。[Microsoft DPAPI 说明](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)。

启动时恢复已保存连接的 ID、端点、资源范围和密钥，因此旧任务不因重启而更换连接。通常需要同一台电脑和同一 Windows 账户；更换账户、重装系统或损坏文件时可能无法恢复。

- 轮换密钥会同步更新已启用保存的加密副本；修改名称或留空密钥不会关闭保存，也不会清空原密钥。
- 取消本机保存会删除该连接的加密副本，当前进程内存中的连接仍可用；删除连接会删除对应的已保存记录。
- 加密或写入失败时返回503并保留原连接和原文件，不改用明文；恢复异常时显示错误并保留原文件，不允许覆盖未恢复的保存记录。
- 未启用保存的连接仍只在当前服务内存中；环境变量连接沿用原有配置方式，不会额外落盘。Windows 以外的平台当前不启用本机密钥保存。

密钥轮换不会改变已冻结任务的内存凭据。如需现有任务立即使用新密钥，在任务详情中显式重新绑定同一连接。保存、恢复和重新绑定均不会调用付费模型。

验证：`scripts/check_local_credentials.py` 使用临时目录和假密钥，涵盖真实 DPAPI、独立进程与应用启动恢复、API 不回显、轮换、取消保存、删除、匿名本机连接、损坏文件和失败回滚。
