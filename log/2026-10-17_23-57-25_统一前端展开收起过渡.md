## 问题与后续注意

- 原生 details 默认会在关闭时立即隐藏正文，仅给内部元素添加动画不能解决关闭瞬间消失，需同时过渡伪元素高度和离散的 content-visibility。
- 实现采用 `@supports` 渐进增强；当前本地浏览器已实测支持 `::details-content`、`interpolate-size` 和 `allow-discrete`。不支持这些 CSS 能力的旧浏览器仍能原生展开/收起，正文高度过渡不会启用。本次未做旧浏览器兼容矩阵。
- 技术依据：[Chrome 官方 details 样式文档](https://developer.chrome.com/blog/styling-details)。作用域仅限 details，避免全局启用内在尺寸插值影响其他组件。
- 原生折叠伪元素不属于 `::before`/`::after`，仅靠原先减少动态效果通配规则不能覆盖它，故需统一时长变量。
- 浏览器观察 API 不提供 DOM `getAnimations`，原始 CDP Animation 方法也不受支持；改为直接采样高度、透明度与最终状态。测试没有注入页面脚本或修改 DOM。
- 主题圆形过渡期间的下一步导航点击可能落在过渡层上；验证时等待主题切换完成再点击，并用新的可访问状态确认所在视图。
- 保留工作区原有文档、AGENTS.md、汇报文件及未跟踪缓存改动，不纳入本次提交；无任务交接请求。
