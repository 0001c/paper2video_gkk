# paper2video
将论文转为视频

## 网页访问

本机启动：`.venv\Scripts\python.exe web/app.py`，访问 `http://127.0.0.1:8848/`。

可信局域网共享：在 PowerShell 中运行 `./scripts/start_web_lan.ps1`。
脚本自动选取有默认网关的物理网卡，显示访问地址，并只允许该 IPv4 私有子网。
也可手动启动：

```powershell
.venv\Scripts\python.exe web/app.py --host 0.0.0.0 --port 8848 --lan-subnet 192.168.31.0/24
```

首次共享需允许 Windows 防火墙的 TCP 8848 入站，并限定远端地址为相应局域网子网。
其他设备连接同一局域网后使用显示的 IP 地址；手机中的 `127.0.0.1` 指向手机自身。
默认仍仅监听本机；局域网内设备共享任务、素材和产物，没有用户账户隔离，请用于可信网络。
审核暂停、确认后配音合片的流程在局域网模式下保持一致。
IP 或网段变化后重新运行脚本，并调整防火墙子网规则；不需要设置路由器公网端口转发。
