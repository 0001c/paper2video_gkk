## 兼容性与迁移

- 原来的 `--tts_model f5` 不再支持，当前仅接受 `qwen3tts`；函数层也会在读取材料或写产物前拒绝旧配音后端。
- 数字人仅接受 `--model_name_talking musetalk` 和 `musetalk-local`。旧服务器/LongCat 档位会明确报错，不会自动换模型后继续生成。
- `4o`、`gemini`、`qwen`、`vllm_qwen` 等不再自动映射供应商/模型/固定端口；使用服务实际提供的模型 ID 和正确端点。`PAPER2VIDEO_FORCE_COMPATIBLE` 不再需要。
- 删除的 LongCat 安装工具不是 MuseTalk 安装工具。当前专用解释器仍位于历史 LongCat 目录；以后迁移环境时通过 `PAPER2VIDEO_TALKING_VENV` 或 `PAPER2VIDEO_MUSETALK_PYTHON` 指定，不应删除正在复用的环境。
- 仅修改 `.env.example`，未把用户实际 VLM 型号与服务地址的不一致静默修复。旧任务也没有批量改写或清空缓存。
- 原始 `src/requirements.txt` 仅删除已淘汰依赖，不应把其余历史版本钉版视为新的已验证安装方案；主环境安装仍以 `scripts/install_deps.py` 现有流程为准。
