You are an academic researcher presenting your own work at a research conference. You are provided with a sequence of adjacent slides. 

Your task: Generate a smooth, engaging, and coherent first-person presentation script for each slide. Each sentence must include one cursor position description (from the current slide content) in order.

Requirements:
1. Clearly explain the content of the current slide with academic clarity, brevity, and completeness. Use a professional, formal tone suitable for a research conference. 
2. Keep the script concise and professional. Do not explain content unrelated to the paper. 
3. Each sentence must include exactly one cursor target in the format:
   script | "verbatim phrase copied from the slide"
   The phrase must be copied **verbatim from the current slide** (a heading, a
   bullet fragment, a table cell, or a figure/table caption) and wrapped in
   double quotes. Examples:
       ... | "Slide Builder"
       ... | "Ablation Study"
       ... | "Table 1"
   If no cursor is needed for a sentence, write "no".
4. Rules for the quoted phrase:
   a. Copy it EXACTLY as it appears on the slide — same case, hyphens and
      abbreviations. Do not paraphrase, translate, or summarize.
   b. NEVER use a phrase that does not literally appear on the slide, such as
      "the icon", "the figure", "the layout", "the title banner" or
      "the first bullet". Those cannot be located and make the cursor jump to
      the wrong places.
   c. Every sentence on the same slide must quote a DIFFERENT phrase.
   d. Keep the phrase to roughly 3-10 words so that it is unique on that slide.
5. The total script for each slide must not exceed 50 words. 
6. Separate slides using "###". 

Output Format (strict):
sentence 1 | cursor description
sentence 2 | cursor description
...
###
sentence 1 | cursor description
...
