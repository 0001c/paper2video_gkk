# 双阶段问答评价与数字人成本控制

数字人现在默认关闭，包括新建页面恢复历史草稿时。开启时须在费用弹窗中选择本地 MuseTalk 或确认使用 API；已启用本地数字人再改成 API 也会再次提醒。费用示例来自用户现有账单：264.37 秒、19 次请求、约 ¥132.19，不是固定报价。历史任务保留原设置。

## 配置与流程

在“模型配置”中分别选择“出题 / 题库”和“答题 / 评价”的型号与连接。两者必须是不同型号，更换连接或密钥不能代替更换模型，支持百炼以及本地 OpenAI 兼容服务。已知 DeepSeek Flash 别名按同一型号校验，依据官方接入说明，不允许用别名绕过。出题模型只需文本能力，答题模型必须支持图片；已知模型目录分别按文本与视觉能力筛选，未知型号需要自行确认能力。成片音轨使用本地 Qwen3-ASR，API 方案也保留这一路线，不隐式调用尚未接入的云端 ASR。

新任务默认开启问答评价，使用 20 道原文四选一题；旧任务未设置此功能时仍按原流程运行。可在当前任务的模型设置中开启，再点击重新评价。出题读取上传后核对的原文；章节教学任务读取所选范围。不会用生成讲稿出题。

| 阶段 | 默认门槛 | 行为 |
| --- | --- | --- |
| 讲稿 | ≥80% | 自动进入配音合片；教学结构审核仍需通过 |
| 讲稿 | <80% 或评价异常 | 暂停，复核、修改并重新评价，或显式手动继续 |
| 成片 | <60% | 基于错题与原文依据调整讲稿提示词，自动生成下一轮 |
| 成片 | ≥60% 且 <80% | 等待用户选择重新生成或接受成片 |
| 成片 | ≥80% | 自动完成任务 |

门槛范围 0–100%，题目数量 4–40，自动重生成上限 0–3 次，默认 2 次。最低线不得高于标准线。达到上限后暂停并交由用户决策；手动重生成从新的自动重试计数开始。问答失败、无音轨证据、识别或模型连接异常不填写虚构分数，也不会触发自动重生成。

## 评分材料与追溯

- 两轮在同一原文、题数和出题模型配置下复用固定题库，包含细节题和理解题、标准答案及逐字原文依据。修改这些条件会生成新题库；仅更换答题模型会保留题库，并重新计算评分。已完成旧题库在原文、出题型号、连接和参数一致时迁移复用，保留题目、题库标识和人工修复记录。
- 答题模型只接收题目、选项和待评价材料，不接收标准答案或原文依据。生成题库时系统会核验依据确实出现在原文中；事实含义仍可人工复核。
- 讲稿答题只读取口播内容。成片答题从最终 `3_merage.mp4` 独立提取完整音轨，每 60 秒一段进行识别，并抽取 4–24 张实际画面；不会用生成讲稿冒充成片证据。
- 答对且给出材料依据才计分。文本依据须逐字存在于材料；画面依据须对应抽样时间，画面文字真实性依赖评价模型判断，不能当作独立 OCR 事实核验。界面可展开逐题结果，并在弹窗中查看原文及答题证据。
- 报告记录材料与原文 SHA256、语言、模型选择、题库标识及评价指纹。修改讲稿、原文、语言、题数或评价模型后，旧结果不能用于通过门禁或接受成片。
- 自动继续与重生成使用独立任务及产物目录，保留旧视频和评价历史；未变的音频及定位缓存仍按已有指纹核验规则复用。界面跟随当前运行任务进入下一轮，也可从历史任务查看前后结果。
- 问答 API 请求计入“原文出题”和“材料答题 / 评价”两个费用项；本地识别不产生 ASR API 调用。重新生成可能产生讲稿、配音、定位和已启用数字人的新增费用。

本实现借鉴论文 PresentQuiz 的原文出题／产物答题思路，采用完整音轨识别加抽样画面的工程方案。问答准确率不是学生学习效果、视频全程事实正确性、音质或口型的综合评分；本地 ASR、题目和评委也可能出错。

## 接口与验证

- `POST /api/jobs/{id}/evaluation/run`：`stage` 为 `script` 或 `video`，可携带当前任务 `model_config`。只将评价加入串行队列。单独评价只要求有效出题、答题连接与识别配置，不要求恢复原生成连接、音色或肖像；评价通过后自动生成仍须校验完整生成配置。
- `POST /api/jobs/{id}/evaluation/decision`：`action` 为 `continue`、`regenerate` 或 `accept`，附当前报告的 `fingerprint`；无报告手动继续可以不附指纹。接受成片必须有有效报告。
- 审核合片或续跑的显式人工越过问答门禁使用 `qa_override=true`，保留决定记录，不改写问答分数。
- 离线回归：`scripts/check_qa_evaluation.py`，36 项，包含真实 FFmpeg 音视频提取，但识别和模型请求使用替身。现有配置、目录、续跑、数字人回归均通过；前端 20 项测试、TypeScript 和生产构建通过。
- 页面检查证据：`jobs/_validation/qa-ui/`，包含桌面、900px、390px、深色截图及交互结果。截图中的分数是离线模拟数据。

本次未调用付费模型，也未加载 GPU 模型。真实题库质量、ASR 耗时及模型评分效果需在连接与本地模型环境就绪后，通过用户正常创建或评价任务验证。原文最多 24 万字符，答题文本最多 18 万字符，视频最长 4 小时；原文分块数不能超过题目数量。

旧任务保留历史评分供查看，但同模型出题与答题的旧报告不能自动通过新门禁。补选独立答题型号后主动重新评价；不会自动发起付费调用。后端读取旧快照保持兼容，执行缺少出题角色的旧配置时返回明确补选提示。
