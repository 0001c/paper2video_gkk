# A2 · 8分钟微课讲稿

## 1. 从损失到参数更新

我们今天要解决的问题是：如何让神经网络的预测误差越来越小？核心思路是——通过调整内部参数，使损失函数 J(w) 逐步下降。

这个过程分三步走：先随机设定一组初始参数，再用它们做前向预测得到输出，最后与真实值比较算出当前损失。

关键在更新这一步：新参数 w_new 等于旧参数 w 减去学习率 eta 乘以损失对参数的导数 dJ/dw。

注意两个细节：eta 必须大于 0；dJ/dw 是损失 J 对参数 w 的导数，不是反过来。导数为正，说明当前参数增大时损失上升，我们就该减小它；导数为负，说明增大参数反而能降损失，减去一个负数就等价于增加它。

为什么是减号？因为梯度 dJ/dw 指向损失增长最快的方向，我们要往反方向走——也就是负梯度方向。这是整个优化过程的数学依据。

后续我们会用教材第15页的计算图例题 e=(a+b)(b+1)，具体演示 b 如何通过两条路径影响 e，并验证链式法则中多路径贡献必须相加、不能相乘的易错点。

## 2. 学习率与优化边界

上一节我们得到参数更新公式：w_new = w - η · ∂J/∂w，其中负梯度 ∂J/∂w 指出当前点损失下降最快的局部方向。

但方向只是第一步——步长由学习率 η 决定，它是一个正实数，直接控制每次更新的幅度。

η 过小，例如 10⁻⁵，每一步更新微乎其微，训练像在粘稠液体中爬行，收敛极慢；η 过大，例如 0.8，容易越过最低点，导致损失反弹、参数震荡，甚至发散到无穷大。

注意：神经网络的损失函数通常是高度非凸的，存在多个局部极小值。梯度下降只能保证收敛到某个局部最优解，无法确保是全局最优。

这意味着优化过程本质上是局部试探——我们依赖当前梯度信息做一步修正，再重新评估。下一步关键问题就来了：这个梯度 ∂J/∂w，如何高效、准确地计算出来？

## 3. 反向传播负责计算梯度

上一节我们确认了负梯度指向损失下降最快的方向，学习率η决定每一步迈多大；但梯度本身——也就是损失对每个参数的偏导数——从哪里来？这正是本页要解决的问题：反向传播负责计算梯度。

整个训练流程严格分为三步：前向传播把输入变成预测，再与真实值比较得出损失；反向传播从损失出发，沿计算图反向传递局部导数，求出每个参数对损失的偏导；最后优化器用这些梯度更新参数。

特别注意：‘求梯度’与‘参数更新’是两个独立环节。就像测绘员先测出山坡各处的坡度（梯度），施工队再据此操作推土机（更新），两者职责分明，不能混淆。

反向传播的核心动作是：从输出端开始，回传局部导数。它不直接计算全局导数，而是把链式法则拆解为每条边上的小导数，再按路径相乘、多路径相加组合起来。

以教材例题e = (a + b)·(b + 1)为例：设c = a + b，d = b + 1，e = c·d；当a=2、b=1时，c=3、d=2、e=6。求∂e/∂b时，b通过两条路径影响e：经c路径贡献∂e/∂c·∂c/∂b = 2×1 = 2；经d路径贡献∂e/∂d·∂d/∂b = 3×1 = 3；总和为5。漏掉任一路径就会得到错误结果。

优化器只接收已算好的梯度值，执行w ← w − η·∇J；它不参与求导。这种分工让系统模块清晰——导航仪负责算路线（梯度），司机只管踩油门（更新）。

## 4. 链式法则与中间结果复用

反向传播要高效计算梯度,核心依赖链式法则——它不是抽象公式,而是计算图中信号回传的数学实现。

当一个输入变量只通过一条路径影响输出时,比如a→c→e,它的偏导就是各段局部导数相乘：∂e/∂a = ∂e/∂c × ∂c/∂a。

但更常见的是多条路径并存。例如变量b同时进入c=a+b和d=b+1,再共同影响e=c·d；这时b对e的总影响必须把两条路径的贡献分别算出后相加,不能相乘。

具体来说,路径b→c→e贡献∂e/∂c·∂c/∂b,路径b→d→e贡献∂e/∂d·∂d/∂b,两者相加才是∂e/∂b。

为避免重复计算,我们复用中间节点的导数。一旦算出∂e/∂c和∂e/∂d,所有上游变量都能直接调用,大幅减少运算量。

这种策略在多个输入、单个标量输出的情形下优势显著——神经网络的损失函数正是如此：成千上万参数输入,一个标量损失输出,反向模式天然匹配。

接下来我们就用教材例题e=(a+b)(b+1)来验证：当a=2,b=1时,c=3,d=2,e=6；∂e/∂c=2,∂e/∂d=3；最终∂e/∂a=2,∂e/∂b=2+3=5,清晰体现‘路径相加’原则。

## 5. E1：教材计算图逐步求导

我们来看这个具体计算图：e等于(a加b)乘以(b加1)，其中a取2，b取1。

先做前向计算：令c等于a加b，得3；d等于b加1，得2；最终e等于c乘d，结果是6。

现在反向求导：e对c的偏导是d，即2；e对d的偏导是c，即3——这是局部导数，只看直接相连的边。

接着链式法则：a只通向c，所以de/da等于de/dc乘以dc/da，即2乘1，结果是2。

而b不同：它既影响c，又影响d。从c路径贡献2×1=2，从d路径贡献3×1=3，总和是5。

关键就在这里：b经过两条路径影响e，必须把两路贡献相加，不能漏项，更不能相乘——这是链式法则在多路径图中的核心规则。

这个例子虽小，却完整呈现了神经网络中反向传播的机制：前向算值，反向沿图回传梯度，每条路径独立计算再叠加。下一页我们将把它嵌入训练流程，看清它如何驱动参数更新。

## 6. 串联训练流程与检查理解

整个神经网络训练流程是：先做前向计算得到预测输出，再与真实标签比较得出损失，接着反向传播求出各参数对损失的梯度，最后用梯度更新参数。

这里必须澄清一个常见误解：反向传播只负责计算梯度，它本身不执行参数更新；更新动作是由梯度下降或随机梯度下降算法完成的。

在反向求导时，链式法则的实现有两条铁律：同一计算路径上的局部导数要相乘，而多条独立路径通向同一个变量时，它们的贡献必须相加——漏掉任何一路都会导致梯度错误。

回顾我们教材中的例题：e = (a + b)(b + 1)，其中b同时影响c = a + b和d = b + 1，再经c和d共同影响e。因此∂e/∂b = (∂e/∂c)(∂c/∂b) + (∂e/∂d)(∂d/∂b) = 2×1 + 3×1 = 5——两路贡献相加，绝不能相乘或遗漏。

更新步骤中，学习率η是一个正标量，用于缩放梯度步长：w ← w − η·∇J(w)。η过小收敛缓慢，过大则可能震荡甚至发散。

更关键的是，神经网络的损失函数通常是非凸的，梯度下降只能找到局部极小值，无法保证全局最优——这正是后续引入动量、Adam等方法的根本动因。
