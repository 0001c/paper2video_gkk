# 当前模型使用清单

更新：2026-10-02。适用分支：`codex/simplify-model-backends`。本页已按精简后的代码更新；精简前的详细清单保存在 Git 提交 `84a5394` 中。

## 当前生成链路

| 环节 | 当前模型/实现 | 本地还是 API | 使用条件 |
| --- | --- | --- | --- |
| 原材料结构化、Beamer 课件生成与编译修复 | 默认模型 ID `deepseek-flash`，兼容 API | API | 网页可指定实际模型 ID 和服务地址 |
| 看课件生成讲稿、焦点描述、可选布局微调 | 默认模型 ID `deepseek-flash`，兼容 API | API | 讲稿模型必须支持图片输入；布局微调默认关闭 |
| 逐页配音、参考音色克隆 | `Qwen/Qwen3-TTS-12Hz-1.7B-Base` | 本地 | 当前唯一已接入配音后端，保留长文本分块、护栏、缓存 |
| 参考音频转写 | `Qwen/Qwen3-ASR-0.6B` | 本地 | 未提供参考文本时按需使用 |
| 字词时间对齐 | `Qwen/Qwen3-ForcedAligner-0.6B` | 本地 | 已知文字与合成音频对齐，输出时间戳 |
| 光标空间定位 | `mPLUG/GUI-Owl-1.5-4B-Instruct` | 本地 | 将焦点描述落成幻灯片坐标 |
| 口型同步数字人 | `TMElyralab/MuseTalk` v1.5 | 本地 | 可选；仅保留 `musetalk-local` 单卡档位 |
| 预置参考音色生成 | `mimo-v2.5-tts` | MiMo API | 选预置音色且缓存未命中时 |
| 按文字设计参考音色 | `mimo-v2.5-tts-voicedesign` | MiMo API | 显式生成/重掷音色时 |

文本与讲稿是两种角色，可以复用同一模型。MiMo 只生成短参考录音，整篇配音仍由本地 Qwen3-TTS 完成。课程规划、审核、缓存、队列不是另一套大模型。

## MuseTalk 配套组件

| 模型 | 功能 | 部署 |
| --- | --- | --- |
| `openai/whisper-tiny` | 提取嘴部生成所需的音频特征，不是主链路 ASR | 本地权重，不调用 OpenAI API |
| `stabilityai/sd-vae-ft-mse` | 人脸图像与潜空间的编码/解码 | 本地 |
| `ManyOtherFunctions/face-parse-bisent` | 人脸解析和嘴部遮罩 | 本地 |

当前下载器只登记四个主链路模型与四个 MuseTalk 组件，共八个权重条目。数字人的输入、输出契约仍由 `talking_gen.py` 和 `talking_config.py` 实现。

## 已从当前生成代码移除

- F5-TTS 与旧 WhisperX 转写回退；TTS 参数不再接受 `f5`。
- LongCat 生成分支、命令构建、文本 prompt、权重/下载登记，以及独立安装、补丁和验证脚本。
- Hallo2、InfiniteTalk 的退役分支；未验证的 `musetalk-server` / `server-8xa6000` / `local-16g` 档位。
- 未接入的 CAM++ 下载登记及依赖安装项；InfiniteTalk、OmniAvatar、Wan 等候选模型的默认资料查询列表。
- GPT/Gemini/DeepInfra/OpenRouter/百炼专用分支、硬编码 localhost vLLM 型号与端口。现在生成链路统一使用兼容 API，模型 ID 原样传给所配置的服务。
- 模板中未接入的 DashScope/Gemini Key、旧数字人低显存开关与 checkpoint 配置。

移除专用路由不等于禁止使用某品牌：兼容服务若支持其实际模型 ID，仍可填写模型 ID 与端点。供应商的非兼容原生 API 需要下一阶段明确接入，不能只填名字就自动切换供应商。

## 配置与边界

1. `.env.example` 的两个默认生成模型均为 `deepseek-flash`，避免模板里型号与端点错配；用户实际 `.env` 没有改写。
2. 先前实际 `.env` 的 VLM 是 `qwen3.5-omni-plus`、兼容地址指向 DeepSeek。使用网页显式模型选择可以覆盖；使用环境回退前仍需自行核对，不代表百炼视频观众已实现。
3. 当前 MuseTalk 继续复用 `E:\ai-models\LongCat-Video\.venv` 中已安装的解释器；这是历史目录名，后端代码已移除，不要为了删除名字误删该环境。
4. 原有权重、独立环境、任务、音色库、成片和历史资料未删除，现有服务未重启。
5. 本次没有执行冒烟、运行测试、模型推理或付费请求。仅完成静态语法、引用、配置及 Git 差异检查，不承诺所有运行场景已验证。

下一阶段的各环节本地/API双选尚未实现，详见 `docs/模型精简与双模式接入准备.md`。
