# 百炼 P7 Wan 数字人开发说明

日期：2026-10-07，Asia/Shanghai。P7 已实现代码与离线验证；未发起真实付费请求、上传用户素材或验收真实口型效果。

## 接入与产物

- 全量流水线从有效 `model_config.avatar` 派生模型。`enabled=false` 不读取素材、不分段、不调用数字人；启用 Wan 时不加载 MuseTalk 或回退本地。
- 直接复用 P6 `avatar_segments.prepare/verify_segment/stitch`：每段解码采样数严格小于 `20 * sample_rate`，默认约 18 秒；整页音频不删减、不加速、不重复插入间隔。
- Wan 请求串行。每段输出最后按原采样时间线拼接，页主 WAV 为唯一最终音轨；输出路径仍为 `talking_wan2.2-s2v/<页号>/<肖像文件主名>/merge_video.mp4`。
- 配置参数 `avatar.parameters.resolution` 为 `480P` 或 `720P`，默认 `480P`。本地数字人保留原空参数契约。
- API 模型能力已标为适配器实现，目录可选与配置检查仍不能证明账号权限、付费额度或生成效果。

## 检测与媒体传输

使用官方临时上传 policy，按目标模型分别申请资源。肖像先绑定 `wan2.2-s2v-detect` 做检测，通过后再绑定 `wan2.2-s2v`；生成音频也绑定生成模型。不能共享两个模型绑定的 `oss://` 地址。

上传 policy 使用官方明确的 `/api/v1/uploads?action=getPolicy&model=...` 入口；检测、生成、任务查询沿用连接显式配置的北京原生 HTTP 地址，不能把兼容聊天地址当媒体接口。OSS 请求只携带本次 policy 字段，模型接口使用 `X-DashScope-OssResourceResolve: enable`。签名、API Key、素材 URL 和完整远程响应只在内存使用。

图片检测缓存按肖像内容、账号范围、模型和端点隔离。音频必须满足 P6 解码与时长检查及 Wan 文件大小限制。临时对象自然过期，未新建生产 OSS，也不提前删除仍被远程任务引用的输入。

## 持久化、恢复与取消

片段记录独立于 P6 `manifest.json`，位于：

```text
talking_wan2.2-s2v/.segments/<page>/<P6 identity>/wan_<模型配置与肖像指纹>/wan-task-0000.json
```

记录保存 `task_id/request_id`、模型、参数、账号范围、无秘密原生端点、片段指纹、供应商状态、本地状态、费用记录 ID、归档路径和文件 hash。页目录另保存 `avatar_segments.json` 摘要，保留所有片段信息；失败恢复不会丢弃后续片段的已知 ID。

提交前先保存状态；收到远程 ID 后立即原子写入，然后轮询。已知 ID 的重跑只查询和归档，不重新上传或提交；超时、连接中断、`UNKNOWN`、缺失远程 ID 或受理结果不明均保守处理，不自动重提。任务记录和结果 URL 有有效期，成功后立即下载归档，下载失败保留 ID 供再查。

任务详情提供远程记录、取消说明和显式对账入口：`POST /api/jobs/{id}/remote-tasks/reconcile`。该入口只查询和下载已知任务，不启动流水线、不上传、不提交；未知 ID 返回 `needs_manual_review`。临时连接重启失效时先使用既有连接重绑入口，不能借用全局 Key。新入口沿用公网登录保护、请求体限制和任务写保护。

取消先写当前任务目录的 `avatar_cancel.json`；子进程经 `PAPER2VIDEO_AVATAR_CANCEL_FILE` 在上传、检测、提交和轮询边界检查。只有供应商查询明确返回 `CANCELED` 才显示确认取消；本地进程停止或取消接口被受理不能证明云端停止。未确认时保留 `cancel_unconfirmed` 和“云端任务可能继续处理/计费”，以及任务 ID 和对账入口。

## 费用账本

复用 `web.model_costs.begin/finish/summary`，新增 `restore(directory, record_id)`。远程恢复更新原费用记录，轮询与下载不新增生成请求计数。

| 模型 | 用量与标准价 |
| --- | --- |
| `wan2.2-s2v-detect` | 成功检测请求 `images`，0.004 元/张；图片检测不通过仍算已成功执行检测 |
| `wan2.2-s2v` | 供应商成功输出 `usage.duration` → `duration_seconds`，`usage.SR` → `resolution`；480P 0.5 元/输出秒，720P 0.9 元/输出秒 |
