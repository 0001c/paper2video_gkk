# 百炼接入 P5/P6 与模型费用统计

## 1. 本轮交付与边界

P5光标API与P6数字人条件分段已实现。关闭数字人时，文字、讲稿视觉、配音和光标定位均可选择百炼API，保留原本地入口；这不是Wan数字人已上线，也不是完整论文到视频成片的效果验收。

- P5：qwen3-vl-plus独立grounding角色、兼容端点、瞬时角色Key；先用PDF坐标，未命中才云定位。图像按比例压缩到长边1008，原图坐标换算不受缩图影响。
- 定位仅解析白名单JSON：found、coordinate_scale=1000、point或bbox。拒绝命令/代码、重复字段、非有限值、越界和歧义；没有eval、点击执行或GUI-Owl隐式回退。未找到目标允许中心位置，非法响应直接失败。
- 配音时间轴直接消费真实word时间戳；句子边界映射到供应商词边界，不在词内按字符均分。时间轴原稿不一致即失败，API路线不加载ForcedAligner。
- 定位缓存绑定模型、提供方、连接scope、端点、图像、定位指令、协议和PDF指纹；本地旧键保留。新API时轴缓存版本为v3，防止命中旧插值算法。
- P6：只有开启数字人时派生片段。采样数严格小于20×sample_rate，正好20秒也拆；默认18秒目标，优先附近词边界，再尝试静音边界，最后安全硬切。无遗漏/重叠音频，不删文本，不加速，不重复加入TTS块间静音。
- 片段记录采样范围、秒范围、文本范围、hash。云时间戳可提供文本范围；缺少匹配时轴的本地音频如实记null，不编造文本范围。本地主页音频保持不变。
- 本地MuseTalk也只收到合法短片段，缓存绑定分段身份、参考图和档位。页视频按累计采样边界映射25fps拼接，以原页主音频作为唯一音轨。允许最多0.15秒模型帧取整不足，否则拒绝补帧掩盖视频缺失；成片复核时长与音轨数量。

P7仍需接Wan检测、上传、异步任务和恢复；可选API ASR没有实现。P8共享产物写入所有权与外部音色变化缓存边界继续保留。用户未开启数字人时不执行本轮20秒规则。

## 2. 前端与接口

沿用纸色/墨绿工作台的TDesign组件、已有模型设置与任务详情，不新增UI依赖。面向内容制作用户，主要任务是确认模型路线及已发生的请求费用，反馈保持清晰克制。

- 光标环节可切本地GUI-Owl / 百炼qwen3-vl-plus；已接入状态与未验证权限区分。
- 数字人本地MuseTalk执行入口已解除P6禁用；切到Wan仍会明确拒绝，不能偷换本地。
- 任务详情新增可展开费用面板；音色面板另列共享音色管理累计费用，不能算成当前任务独占。
- `GET /api/jobs/{job_id}/model-costs`：按任务结果目录累计各环节请求、供应商用量、已知费用估算、未知请求数。
- `GET /api/model-costs/voices`：音色创建/试听累计；查询状态和目录GET不会计成推理。
- 两个接口只读，不生成媒体、不触发模型或账本写入。加载/错误/空数据/未知价格分别显示；续跑共享结果目录会显示同一累计账本。

费用账本`model_usage/<request_id>.json`在发送前写受理不明记录，返回后仅保存白名单数值用量、状态、价格版本和估算，不保存请求内容/密钥/签名URL。覆盖结构化文字、课件生成及修复、讲稿/布局视觉、定位、TTS每块、独立音色动作。缓存命中不新增请求；已请求但本地解析失败仍保留供应商用量与费用。本次真实TTS验证失败的两次请求也计入累计，未因最终成功而漏记。

- 本地TTS/ASR/GUI-Owl/MuseTalk算力、电费与其他平台费用不在百炼账本中；未调用/未记录不等于这些成本为零。
- 标准按量估算没有扣除免费额度、Batch/上下文缓存折扣、合同价格或OSS费用。用量准确不等于扣费准确，实际账户账单仍需阿里云账单核对；本轮只使用模型API Key，没有接财务账单接口。
- 后续更新价格需新版本，历史单次费用已固化。SDK内部百炼自动重试设为0；项目显式重试会记录独立尝试，失败/超时可能计费，不凭本地状态推定退款。
