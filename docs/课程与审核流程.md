# 课程时长与课件讲稿审核

2026-10-01。Web 新建任务现在统一采用：准备课件与讲稿 → 暂停审核 → 用户确认 → 配音、光标定位与合片。论文、教材、故事、小说/漫画、通用内容都适用。原有声音克隆试听入口保留。

## 使用方法

1. 上传素材并完成提取预览，检查文字是否完整。
2. 选择讲解内容类型、语言和页数。教材/课程会默认打开教学设置；其他内容也可以主动勾选。
3. 做长课时，选择本次章节/小节，填写受众、目标、重点和讲解方式。时长可自动分配，也可设置 1～180 分钟，例如 40 分钟。
4. 点击“预览 / 更新教案”，调整分节标题和分钟数，再勾选确认。自定义模式的分节时间之和必须等于目标时间。改变素材、范围、语言、页数或教学设置后，需要重新更新并确认。
5. 点击“生成课件与讲稿”。此步可能调用模型，但不会合成讲稿音频或视频；完成后状态为“课件与讲稿待审核”。
6. 在任务详情逐页核对课件和讲稿。可以直接编辑并保存，也可以点击“调用模型重写本页”；后者明确提示模型调用费用，其他页保留，重写完成后再次等待审核。
7. 勾选“已核对所有课件和讲稿”，再点击“确认并生成配音视频”。已审核讲稿严格复用，不会因讲稿损坏而偷偷改为模型重写。

审核中的课件可以点击放大和下载；当前编辑器编辑的是讲稿及光标目标，不提供幻灯片源码的可视化编辑。课件内容需要大改时，应修改素材/教案后新建准备任务。

## 时长口径

- “目标分钟数”表示视频希望讲多久；任务进度中的“剩余”表示机器还需要等多久。两者分别计算。
- 语速只用于讲稿长度预算，默认中文 220 字/分钟。请按自己音色的实际播放情况调整预算语速，不会修改音色或拉伸音频。
- 教案预览按材料长度分配时间和页数，是本机确定性计算，不是模型已经检查过教学内容。
- 所有类型讲稿按实际课件逐页生成，附相邻课件文字保持衔接；课程另附对应源材料与时间预算，覆盖短讲稿模板的固定长度限制。教师直接讲概念、原因、例子与推导，论文讲研究，故事讲情节，不把描述版式或页码当作讲解。补充常识与类比应准确，不得虚构研究数据、原作情节或原题答案。
- 讲稿阶段显示已完成页数、并发数和实际生成速度推算的剩余时间。首个新生成页完成前不显示剩余估计；缓存命中不计入生成速度。原来的固定 110 秒是整批讲稿阶段估计，不能代表单页或长课实际耗时，已移除。
- 审核前显示讲稿估算时长；偏离目标超过 ±10% 会提示。音频生成后显示实际时长与偏差，仍需人工决定哪些页补充或精简。
- ±10% 是提示阈值，不是生成保证；没有自动反复重写直到命中时长的循环。尚未进行完整 40 分钟真实模型/GPU 出片标定。

## 讲稿编辑与恢复

每行保留以下形式，光标短语应来自本页可见文字；没有适合目标时使用 `no`：

```text
这里解释集合与元素之间的归属关系。 | 集合
接下来通过一个例题回顾。 | no
```

网页维护分页，页内不能自行插入 `###`。保存时提交全部页，后端检查数量、格式和版本；每页最多 20000 字符，总正文最多 200000 字符，审核请求体还受 512000 字节限制。

- 旧讲稿保存在结果目录的 `script_versions/`，文件名是旧内容指纹；重新读取前会提示未保存编辑。
- 人工保存、局部重写和整套重写都采用原子替换并保留旧版本，中途取消不会截断原讲稿。每次新重写使用独立缓存标识；同一次失败恢复才复用成功页，避免“重写”却仍返回旧缓存。
- 准备失败/取消可以“继续准备课件与讲稿”，恢复后仍需审核；局部重写失败恢复保留原选中页范围。
- 所有类型讲稿按页缓存，未变化且已完成的页可以复用；并发完成的结果按原页序输出。失败保留成功页，恢复只生成缺失页；未选中页不会重写。
- 旧任务不会自动替换讲稿或提示词。审核界面重写时可勾选“使用当前内容类型的最新讲稿模板”，为新重写任务保存新模板，原任务快照保留。
- 长页配音拆为不超过 400 字符的片段；页级与片段级都按文字、参考音色和配置验证缓存。中途失败保留已经完成的音频片段。
- 修改一页，只更新相关页音频；参考音色变化会使相关音频缓存失效。定位坐标和强制对齐也验证对应输入后复用，视频最终重新合成。
- 审核保存、重写或配音任务共用一份结果目录。该目录已有排队/运行任务时，拒绝另一个覆盖操作；过期版本不能覆盖新版本。
- 全局课件缓存只在初始准备阶段读取，续跑不会用缓存覆盖手工审核讲稿，也不会把修改后的讲稿回写到原初始缓存。

## 课程章节输出

课程模式在配音后写入 `course_timing.json`、`chapters.json` 和 `chapters.txt`，时间轴按完整页音频长度累计，包含片段停顿。成片额外生成带内嵌章节的 `course_video.mp4`，页面优先播放它，并提供章节跳转按钮。原 `3_merage.mp4` 保留。

## 素材边界

- 幻灯片目标 4～40 页；所选小节数不能超过页数，最多选择 40 项。单页讲稿预算超过 3000 单位时，需要加页或缩短目标时间。
- 标题识别覆盖 Word 提取的 Markdown 标题、常规章节编号、LaTeX chapter/section 等；最多列出前 200 个标题。PDF 没有可靠标题时，请单独上传选定小节，不能根据页码猜测教学范围。
- 选整章包含子节，禁止同时选择父章与其子节。结构化只读取选择的正文，不再重新把整个源文档送入结构化。
- LaTeX 普通 `input/include` 会在工程目录内展开；不执行 TeX。缺失子文件、工程外引用、循环或超过 16 层嵌套会明确拒绝；展开总量最多 2000000 字符，复杂宏驱动的输入建议先导出 PDF/Word。
- 已选正文最多 150000 字符。单小节超过 24000 字符时，讲稿请求按页取有重叠的正文窗口，建议拆成更小的教学段落，避免跨窗口推导缺少上下文。
- 教学范围按正文控制，源文件配图提取仍沿用原工程逻辑；需要在审核时核对课件是否引用了范围外图片，以及公式、数字和例题答案是否正确。
- 产物缓存版本升级到 3，课程与论文结构化模式、模型与服务地址参与指纹；讲稿生成方式改变也使旧准备缓存失效。旧缓存文件不删除，新版本首次准备可能需要重新调用生成接口。

## 模型与并发

接口凭据下可选择“文字模型”和“讲稿 / 视觉模型”。填写凭据后自动读取服务商的模型列表，也可刷新、搜索候选或创建手动模型 ID。文字模型用于结构化和课件；讲稿模型必须支持图像输入，模型列表本身不能证明视觉能力。列表接口不可用时仍可手动输入。新任务保存选择，审核重写沿用任务保存的模型。

连接自检异步执行，等待服务商时不阻塞任务进度和其他请求；空回复会提示检查模型能力、输出限制或额度。续跑和恢复按字段合并本任务凭据，补填 Key 不丢服务地址，补填地址不丢 Key。重启服务后内存凭据仍需重新提供；它们不会写入任务文件。

讲稿默认同时请求 3 页，可配置 1～8。并发只用于模型讲稿请求，本机配音、定位与合片仍按原队列执行。429、临时服务错误及连接超时会有限重试，凭据错误不重试；服务商限流或并发效果不佳时建议降到 1。提速取决于服务商吞吐，不能保证三倍速度。

## 本机审核 API 与 CLI

请求模型定义在 `web/app.py`，动态规范为 `/openapi.json`，交互文档为 `/docs`。教学设置的业务校验与预览、任务创建共用 `course.build_plan`，避免两个入口产生不同教案。

| 方法与路径 | 行为 |
| --- | --- |
| GET `/api/course/source/{ingest_id}` | 获取可选教学章节 |
| POST `/api/course/plan` | 本机预览教案，返回确认 token |
| POST `/api/models` | 用所填凭据读取兼容接口模型列表，不保存此次凭据 |
| GET `/api/jobs/{job_id}/review` | 完整讲稿页、版本及时间报告 |
| PUT `/api/jobs/{job_id}/review` | `version` + 全量 `pages`，保存讲稿 |
| POST `/api/jobs/{job_id}/review/run` | `render` 确认配音合片，或 `regenerate` 重写零基 `page_ids` |
| POST `/api/jobs/{job_id}/prepare-retry` | 失败/取消的准备任务恢复 |

新增写入默认只接受本机 loopback；使用 `--host 0.0.0.0 --lan-subnet <可信私有子网>` 可显式允许局域网读取及写入。浏览器 Origin 必须与服务同源，局域网模式同时检查来源 IP 和 Host，不信任转发头；子网外访问被拒绝。该模式共享任务和产物，不能作为已鉴权的公网接口。错误输入返回 422 并指出字段，版本/占用冲突返回 409，超限返回 413。配音动作不会删除素材或历史讲稿。

CLI 不依赖第三方包，读取 JSON 后编辑 `pages`：

```powershell
python scripts/review_cli.py job_实际ID | Out-File review.json -Encoding utf8
python scripts/review_cli.py job_实际ID --save review.json --dry-run
python scripts/review_cli.py job_实际ID --save review.json
# 以下命令代表明确确认配音合片
python scripts/review_cli.py job_实际ID --save review.json --render
# 以下命令可能产生模型费用，页面编号从 1 开始
python scripts/review_cli.py job_实际ID --save review.json --regenerate-page 2
```

保存后需要重新 GET 最新版本再做下一次操作。直接使用旧 JSON 的 version 会被拒绝。命令行直跑 `pipeline.py` 时，应显式设置 `--review_before_render True` 才会采用审核暂停；Web 已统一开启。

## 前端分区与说明

页面采用暖纸色与墨绿色的内容制作工作台风格，暗色使用深墨绿表面。页首显示“编排内容 → 审核课件 → 生成视频”，运行环境默认收起，任务导航使用下划线。新建任务桌面左侧为分区目录，点击目录会展开对应分区；窄屏目录转为顶部换行排列，表单转为单列。

新建任务按素材、语言与内容类型、教学范围、音色、视频光标、接口凭据、生成审核七个分区呈现（未开启课程设置时不显示教学范围）。点击分区标题可折叠或展开，键盘 Enter / Space 同样可用。标题栏始终显示简短配置摘要。

折叠采用约 320ms 的高度裁切，内容随边框逐渐露出；控件保持挂载，已选文件、文字、提示词和审核讲稿不会因折叠丢失。关闭的内容退出键盘焦点范围。折叠状态保留在当前页面，刷新后主要分区默认展开、高级设置默认折叠；文字草稿仍按原逻辑恢复。

标题或字段旁的问号采用 14px SVG，保留更大的透明点击区域；展开箭头使用固定 16px SVG 原位旋转，避免字符基线造成上下移动。问号可点击查看说明，按 Escape 或点击浮层外部关闭。重要说明使用琥珀色问号，并在浮层中标注“重要提示”。错误、当前缺项、教案确认和审核确认仍直接显示，不会藏入问号。

主题切换继续采用圆形擦换：亮色新快照在动画启动前先裁切为零半径，动画结束后保持最后一帧直至快照销毁，避免全屏闪出。减少动效或不支持 View Transitions 的浏览器直接切换主题。原生滚动条预留稳定宽度。

## 视频光标样式选择

新建任务的「视频光标」区域及任务的「课件与讲稿审核」区域均可选择光标。提供红色光点、蓝色光点、金色圆环、青色准星、白色箭头、手型指针、经典红箭头，以及「不显示光标」。每个素材同时预览浅色和深色背景，可用键盘方向键选择。

大小可选小（75%）、标准（100%）或大（150%），随视频画幅缩放。箭头以尖端、手型以指尖、光点/圆环/准星以圆心定位。新任务默认红色光点；没有配置这些字段的旧任务与 CLI 保留经典红箭头。

新任务的选择保存在本机草稿；审核区的选择在确认生成视频或重写时传给新任务。只保存讲稿不会更新任务的光标配置。更换光标仅影响最终合成画面，未变化的课件、讲稿、配音及定位结果仍可复用，已有视频不会自动变化。

API 配置字段为 `cursor_style` 和 `cursor_scale`。`GET /api/options` 返回 `cursors` 列表，`GET /api/cursors/{style}.png` 返回白名单素材。创建任务的 `config`、续跑请求及审核生成请求均接受这两个字段。

CLI 示例：

```powershell
# 附加到原有 pipeline.py / pipeline_light.py 命令
--cursor_style ring-gold --cursor_scale 1.5
```

样式 ID：`laser-red`、`laser-blue`、`ring-gold`、`cross-teal`、`arrow-white`、`hand-white`、`classic-red`、`none`。素材源程序为 `scripts/build_cursor_assets.py`，使用已有 Pillow 绘制透明 PNG，不新增依赖。

光标冒烟测试：`python scripts/smoke_cursor_styles.py --media`。覆盖配置透传、旧任务默认、素材透明度、缓存隔离、真实视频热点与末目标保持，以及 1,000 个光标目标的合成。真实媒体测试需要 PATH 中可用的 FFmpeg。
