# 报纸风格折叠分区、问号说明与主题闪屏修复

## 已完成

- 新建任务的素材、语言与类型、教学范围、音色、视频光标、接口凭据、生成审核均使用统一 Section 边界：直角细边框、较深顶线、编号、衬线标题与配置摘要，沿用原配色和 TDesign，不新增依赖。
- 主分区默认展开，高级提示词与章节范围默认折叠；标题按钮有 aria-expanded / aria-controls，可使用 Enter / Space。用 CSS grid 0fr / 1fr 与 overflow:hidden 实现约 320ms 高度裁切，不淡入、不卸载内容；关闭时用 inert 与 aria-hidden 隔离键盘焦点。减少动效时取消延迟。
- 普通操作说明迁入标题或字段旁的 Help 问号。复用 TDesign Popup 挂载到 body，避免被折叠裁切容器截断；可点击、Escape 及外部点击关闭。素材核对、凭据本机保存、视觉模型能力、提示词格式及审核要求等重要说明采用琥珀色高亮及文字标记。浅色重要问号使用更深墨色，以满足小文字对比度。
- 当前提取失败/警告、缺项、模型列表异常、教案与审核确认、预算偏差仍直接显示。文案搬迁不改变模型接口、生成行为、凭据存储或审核暂停流程。
- 审核界面也接入相同分区与问号；讲稿输出格式说明单独高亮。原始讲稿和任务没有写入。
- 主题修复：在 startViewTransition 之前记录圆心 CSS 变量，新亮色快照在 ready 之前就有 circle(0px) 初始裁切，WAAPI fill:both 保持末帧到快照移除；保留 old/new 正常混合与层级，滚动条稳定预留宽度。

## 遇到的问题与后续注意

- 仅在 ready 后启动裁切会留下新亮色快照尚未受限的绘制窗口；无 fill 时末尾也可能返回初始裁切。本次同时保护起始与结束阶段，互斥及降级逻辑保留。
- 浏览器检查发现关闭 ::view-transition-group(root) 的动画会失去快照尺寸，使旧页面消失而露出白底。已移除该重置，只关闭 old/new 图像交叉淡化，并增加回归断言。未来勿将 group 的几何动画与默认淡化混为一谈。
- 弹层不能放在 section-reveal 内直接用绝对定位，否则会被 overflow:hidden 截断；复用现有库的 body 浮层即可。重要提示不只依赖颜色，浮层也有“重要提示”文字。
- CSS grid 裁切节点需 min-height:0；内层单独承载 padding。禁止通过条件渲染/hidden 属性移除表单，否则动画突兀且文件选择与未保存输入会丢失。
- 折叠是当前页面的展示状态，没有额外本机存储配置。禁用状态仍遵循原提交 fieldset；不能在准备提交时修改表单。
- CUA 的只读 DOM 接口不暴露 document.getAnimations；使用支持的伪元素 computedStyle 与实际截图观察主题转场。没有绕过浏览器权限或换用隐藏控制接口。
- 使用临时同源浏览器标签验证并关闭；恢复暗色、原有 30 页草稿、新任务视图和原先记住的旧任务。没有更改系统减少动效设置或保存凭据。
