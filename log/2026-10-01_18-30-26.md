# 项目启动方式确认

- 用户问题：这个项目怎么启动？
- 已检查：web/README.md、前端 package.json、项目协作规则和 .workbuddy/memory 历史笔记。此前没有 log 文件夹。
- 当前环境：.venv/Scripts/python.exe、web/static/index.html、web/frontend/node_modules 均存在。
- 启动：在项目根目录执行 .\.venv\Scripts\python.exe web/app.py，访问 http://127.0.0.1:8848。停止用 Ctrl+C。
- 前端修改后：进入 web/frontend 执行 npm run build，然后从根目录启动后端。
- 端口冲突：加 --auto-port，按终端输出访问实际端口；或 --port 8849。
- 冒烟检查：执行虚拟环境 Python 的 web/app.py --help，退出码 0。未启动常驻服务，未执行视频生成任务。
- 需注意：出现 FastAPI on_event 弃用提示，不影响本次入口检查；终端可能有中文编码显示问题。历史日志记载本机代理可能导致 localhost 返回 502，可设置 NO_PROXY=127.0.0.1,localhost。
- 数据边界：工作区已有三处用户修改，未改动、未纳入提交。历史冒烟测试曾误删真实任务，本次仅检查启动入口。
