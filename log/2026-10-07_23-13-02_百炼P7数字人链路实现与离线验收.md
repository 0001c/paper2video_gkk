## 问题与修复

- 隔离执行器多次报 `helper_unknown_error: setup refresh had errors`；经审批的 `require_escalated` 项目命令可运行，使用显式 PowerShell 与 `login:false`。没有因此更换分支或修改系统配置。
- Windows 测试夹具用默认编码读取 UTF-8、含中文路径的 JSON 导致无效转义；修复夹具明确 `encoding='utf-8'`，生产读取一直明确 UTF-8。
- Web 首轮夹具默认 `testclient` 不属允许的本机地址而返回 503；改为 loopback 测试客户端，没有放宽真实访问守卫。
- 独立审查发现检测成功状态写入与费用 finish 间的退出竞态；缓存恢复补齐原账本。已确认费用不会被后续取消、本地下载失败或缺失用量覆写成未知。
- 下载仅看 `ftyp` 会错误缓存截断 MP4；新增 FFprobe 视频流/正时长验证，失败保留原远程 ID 和已发生费用，允许再查归档。
- 旧前端仍有“等待 P6”硬阻挡及“Wan 待 P7”文案，会使已接入模型不能创建任务；已移除并加回归。四种供应商失败/超时状态明确投影，保留可恢复 ID。
- 中文异步管理文档的取消路由有缺斜杠排版，交叉核对官方英文 `/tasks/{task_id}/cancel`；仅 PENDING 阶段尝试取消，接口 HTTP 200 不能当取消确认。
- Windows 文件锁竞争时第二持有者可能在读取锁字节时先抛 PermissionError；改为 fstat 检查尺寸，并把初始化与加锁放在同一受控错误路径，测试证明并发操作明确拒绝且不会重复请求。
- 肖像按真实解码格式和静态帧检查，拒绝 PNG 扩展名伪装 GIF 和 APNG。巨大数值、NaN、列表状态及嵌套错误结构均保守处理，不发无效素材检测、不回落本地。

## 未来注意与边界

- 已知 ID 永不因输入 URL 过期或本地进程重启重提。临时输入资源 48 小时且按模型/主账号绑定；远程任务与结果 URL 仅保留有限时间（通常 24 小时），成功必须及时归档。
- 重新绑定需保持原账号范围和端点。服务内存连接重启失效时不能静默使用全局 Key；CLI 与 Web 的任务环境仍需明确有效凭据。
- 输入/结果签名 URL、Key、Authorization 和完整响应不持久化；上传 policy 固定官方入口，不能从 workspace 聊天/原生基址猜上传地址。
- 取消没有确认时不要清理被已提交云任务引用的输入或删除远程 ID。kill 失败时保留“本地尚未确认停止”，并阻止运行进程与对账并发写记录。
- 尚未授权真实数字人效果/口型、账号权限、上传可用性、远程取消权限/阶段、不同帧率及长课程漂移验收。生产私有 OSS 与共享产物写入治理属于后续 P8，不宣称全链路生产已验收。
- 本轮未创建 Handover；用户未要求任务交接。后续任务开始应先读本日志与 `docs/百炼接入P7数字人开发说明.md`。
