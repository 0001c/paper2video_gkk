# 百炼接入 P2：目录与前端切换

## 本阶段交付

- 后端：兼容与原生目录按ID合并；先按角色、已实现协议及生命周期过滤，再分页。查询游标绑定连接、角色、过滤条件、分页大小、目录版本与生命周期日期。
- 前端：百炼全API、保留现有本地推理、自定义三个预设；文字、视觉、配音、ASR、定位与数字人独立保留运行方式/型号/连接。时间轴来源随TTS切换。
- 连接抽屉：创建连接、编辑名称、轮换密钥、删除临时连接。创建成功后清空密钥，转入编辑已有连接，避免刷新连接列表失败后再次创建。
- 草稿v2：只保存允许的表单字段和脱敏模型引用。首次加载删除`p2v.apiKey`和记住开关，不把历史浏览器密钥自动上传。旧型号与本地路线保留为待重新绑定的自定义组合。
- 创建任务只提交`config.model_config`；审核继续、准备重试、重跑提交任务自己的`model_config`，不继承新任务草稿。旧任务使用独立、仅当前页面内存的凭据恢复入口。
- 任务详情展示模型、连接范围、目录来源/时间、时间轴及数字人策略；支持同范围同端点的连接重新绑定，绑定不启动执行。
- 结构化422错误展示字段路径；用户输入保留。浏览器不再自动拉目录，也不再使用`/api/key/verify`作为默认自检。

## 实际接口

### GET /api/options

原有语言预设、光标、音色等字段不变。`model_configuration`除P1生成schema/implemented外，新增：

`presets`、`recommended_models`、`local_models`、`roles`、`catalog_verification`。

本地文本/视觉是自行部署的兼容服务，不是新增的权重加载器。“保留现有本地推理”预设的媒体环节使用已有本地模型，文本/视觉仍需明确的兼容连接。

### POST /api/models

v2请求：

```json
{"connection_id":"conn_example","role":"vision","include_retiring":false,"limit":100,"cursor":null,"refresh":false}
```

- `role`为text/vision/tts/asr/grounding/avatar，limit严格1至100。
- `refresh=false`只读取进程缓存/历史快照，不请求服务商。快照只匹配原工作空间的百炼兼容端点，并标注不代表当前账号权限。
- `refresh=true`只执行目录GET，禁用跟随重定向，每次响应限制5MiB，兼容/原生最多各100页；未完成完整分页时不发布半成品目录。
- 原生目录使用显式native HTTP base；缺失时仅为目录GET拼同一已校验百炼主机的`/api/v1/models`，不据此推断未来推理/WS端点。
- 合并目录保留compatible/native来源；兼容列表中的未知模态只能标记capability_unknown，不能宣称已验证视觉效果。
- 响应含items、next_cursor、total、source、catalog_time、warnings。型号项含selectable、adapter_implemented、status、verification和offline_time。
- 已下线/生命周期无法解析的型号不可新执行。将下线型号默认不推荐/不显示，显式查看后带原下线时间；原目录未给时区，代码仅按UTC日历日期保守分类，不能视为精确下线时刻确认。
- 刷新失败保留原缓存/快照，返回明确警告，不显示“连接成功”，也不验证推理权限、余额或效果。
- 旧`{api_key,api_base}`请求仍返回字符串列表及弃用提示，删除500条截断；新旧请求字段不可混用。新前端不使用此旧入口。

### POST /api/model-config/validate

新增`review_before_render`、`reuse_script`、`require_reuse_script`严格布尔字段，用于区分准备/审核/复用讲稿所需角色。

- “检查准备阶段”：requested_stages为1/2，review_before_render=true，默认只需要文字/视觉。
- “检查全链路”：requested_stages为1/2/3，review_before_render=false，按真实依赖校验TTS/定位/ASR/数字人。
- 使用当前选择的voice及已有portrait_path；检查本身不上传肖像、识别录音、检测人脸或合成试听。
- 仅配置合法不等于真实可运行。API媒体尚未接入时，返回adapter_not_implemented，不回退本地。

## 使用步骤与边界

1. 用户自行加载新版后端，再刷新前端。开发期间未重启任何服务；若前端读到P1 options，会阻止提交并提示后端尚未加载P2。
2. 管理连接中填自己的密钥/端点。环境连接由服务端环境变量配置，页面不能修改；没有把此前聊天中的密钥写入任何配置文件。
3. 保存连接后重新应用预设或逐角色选择连接。API角色必须有合法连接引用，但非当前执行角色不要求密钥/适配器就绪。
4. 当前要实际准备课件，关闭数字人，使用默认/上传参考音色；选择已有本地媒体路线后再检查全链路配置。P3前文字/视觉必须共享一个兼容连接。
5. 开启数字人时肖像必填，不会自动关闭。策略为单段严格小于20秒、目标18秒；自动分段拼接的代码仍待P6。关闭时没有数字人20秒限制；不改课程/页/整片总时长。
6. 全API预设可以保存规划、在文字/视觉配置合法时进行准备阶段，但配音、云音色、API定位/时间轴、数字人尚待P3至P7，当前不能全链路执行。
7. 轮换连接密钥不改变任务已经冻结的密钥。需要恢复旧任务时，重建相同scope/端点的连接并显式重新绑定；可绑定原连接以重新冻结轮换后的密钥，不自动续跑。
8. 任务内模型编辑是下一次明确执行的覆盖值，不直接改历史产物。当前共享结果目录/缓存行为未重新设计，后续指纹隔离与远程任务对账留给P8。
