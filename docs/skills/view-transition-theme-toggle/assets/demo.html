圆形扩散主题切换

View Transitions + clip-path
在这里任意位置点一下

变亮时从点击位置扩散，变暗时收缩旧亮色快照，覆盖到最远的角落

① 起点

取 event.clientX / clientY，不是按钮中心。

② 半径

Math.hypot(max(x, W-x), max(y, H-y)) —— 到最远角的斜边。

③ 画圆

clip-path: circle(r at x y)，挂在根元素上。

④ 动起来

startViewTransition 包住主题变更，在 .ready 后跑 animate()。

本页已内置的工程化处理

  • 不支持 View Transitions 的浏览器自动降级为无动画切换（功能不受影响）
  • 开启系统「减少动效」后跳过扩散动画
  • 键盘触发（event.detail === 0）时优先从按钮中心擦换
  • 动画期间加互斥锁；每轮结束清理填充动画，避免影响下次切换
  • 准备与收尾共用有限等待，异常时跳过过渡并解锁；迟到回调不重复提交主题
  • 同步设置 color-scheme，滚动条与表单控件一起变色
  • 首屏内联脚本提前打主题，刷新无亮暗闪烁
