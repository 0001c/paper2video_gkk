# 百炼模型配置前端设计

方案日期：2026-10-03。状态：交互与布局规格，不是已上线页面或已完成视觉验收。

## 1. 设计定位

- 用户：制作论文讲解/课程视频的研究者、教师，不要求理解HTTP与WebSocket协议。
- 主任务：选择可运行的模型组合，确认云端素材使用和数字人规则，再进入原有审核/生成流程。
- 风格：沿用当前纸色、墨绿、TDesign与Section布局，保持生产工作台的沉稳，不另建营销式页面。
- 现有浅色基调`#f4f3ee / #fffefb / #202c25 / #2e6454`及深色主题不替换；控件延续38px高度与现有小圆角。错误/等待/成功不仅依赖颜色，还需文字与图标。
- 保留主题切换动画、材料上传、课程规划和ReviewPanel，不在本任务顺手重构页面结构。

## 2. 页面结构

模型区放在材料/课程基础配置之后、声音与数字人区之前。默认显示简洁预设，逐环节设置可展开。

```text
模型配置                                  [检查配置]
┌─────────────────────────────────────────────────────┐
│ [百炼全 API] [保留现有本地推理] [自定义组合]           │
│ 运行摘要：百炼 5 项 · 按需识别 · 时间轴随配音返回       │
│ 连接：北京工作空间 [已配置/需要配置] [管理连接]         │
│ [展开逐环节设置]                                      │
└─────────────────────────────────────────────────────┘
声音配置
  [系统音色] [上传录音复刻] [文字设计] [已有资源]
  目标：CosyVoice · 时间戳：支持/未知/不支持
数字人配置
  [开启数字人]  [上传肖像]  后端：[百炼 API / 本地]
  开启时：单段严格小于20秒；长页自动分段拼接，不限整片
  关闭时：不施加数字人20秒分段限制
提交摘要
  执行环节、素材传往百炼的说明、配置校验状态
  [进入审核/开始生成] [保存草稿]
```

模型数按当前真正需要执行的环节动态计算，示意图中的“5项”不是固定文案。ASR若已有参考文本则标“本任务不需要”，数字人关闭则不计入。

## 3. 模型区字段与行为

| 字段 | 控件/展示 | 规则 |
| --- | --- | --- |
| preset | 分段选择器 | 应用预设只改模型配置；旧任务不自动迁移为百炼默认 |
| text | 模式选择 + 连接 + 可搜索型号 | 用于结构/课件/课程/修复，默认qwen3.8-flash |
| vision | 同上 | 用于逐页理解/讲稿，默认qwen3-vl-plus |
| tts | 同上 | 默认cosyvoice-v3.5-plus；切换触发音色兼容检查 |
| asr | 同上 + 按需标签 | 无需识别时折叠，保留配置但不要求就绪 |
| grounding | 同上 | 默认qwen3-vl-plus；与vision独立保存，初始预设可共用连接 |
| timing.source | 只读来源；高级区可显式改混合对齐 | API默认为tts_timestamp；本地为local_forced_aligner |
| avatar.enabled | 明确开关 | 唯一生效开关；缺肖像不能悄悄降级成关闭 |
| avatar.mode/model | API/本地 + 型号 | 关闭时折叠，不运行、不鉴权；开启时显示Wan/MuseTalk |
| script_concurrency | 原有1至8数字控件 | 默认3，继续属于讲稿并发，不控制Wan并发 |
| 实际组合 | 只读摘要 | 包含非百炼API/本地推理则显示“混合”，不能仍写“全API” |

展开表格列为“环节 / 运行方式 / 连接 / 型号 / 可用状态”，同一个型号可在不同环节出现，但选择值独立。禁止显示未实现的本地声音设计或假ForcedAligner API。

### 3.1 型号选择

- 下拉按环节过滤，先显示推荐且适配器已完成的型号，再显示其他已适配型号；不把518条目录平铺。
- 每项显示型号ID、协议支持状态、下线提示；能力标签只能说明目录声明，不是执行验证。
- 定位/音色/时间戳等特定能力必须由适配器能力表限定，不能仅凭Vision/TTS模态开放全部选项。
- API候选目录可搜索；缺少已实现协议的候选不可提交，显示“目录可见，待接入”。
- 本地兼容文本/视觉允许手填已部署型号，标“手动配置，服务未验证”；仍要求明确支持的兼容协议，不自动发现本地权重。
- 保存历史型号不自动替换；已下线/不适配时保留只读展示，并阻止以该配置新执行。
- 刷新目录是用户主动动作，连接配置后可以提示刷新，不自动循环GET或推理。保留旧请求版本防止异步响应串线。

### 3.2 预设应用过程

1. 应用预设并更新模型摘要；用户再改单个环节时preset变为custom。
2. 保留材料、语言、课程总时长、提示词、肖像与选中音色的资源引用。
3. 原音色不适配新TTS时标红“请重新选择音色”，不后台自动创建云音色或改变音色。
4. 重新运行纯配置校验；保留正在输入的密钥，清除旧配置校验通过标记。
5. 不自动开始生成、不自动下载本地权重、不自动执行云端连接测试。

## 4. 连接配置

在现有设置区域使用TDesign抽屉，不新建独立配置应用。

| 字段/状态 | 交互 |
| --- | --- |
| 连接名称 | 用户可读名称，如“北京百炼”或“本地视觉服务” |
| 提供方 | 百炼 / 本地OpenAI兼容；不显示泛化到所有云厂商的未实现选项 |
| API Key | 密码控件，仅首次/换Key输入，提交后清空；不从服务端取回原值 |
| 兼容地址 | 百炼默认给定工作空间；允许受信配置范围内修改 |
| 原生HTTP/WebSocket | 百炼连接展示已推导地址；高级修改受后端规则校验 |
| 保存来源 | 服务端环境配置 / 本次服务进程内有效，明确重启影响 |
| 连接状态 | 未配置、格式有效、目录可读取、失效；不要以绿色“可用”暗示所有模型推理已成功 |
| 检查配置 | 仅本地schema、依赖及资源归属检查，不发推理、不上传媒体 |
| 刷新目录 | 明确只读网络操作，显示目录时间；失败保留旧目录并标过期 |

删除现有默认“记住API Key”逻辑。`storage.ts`迁移时移除`p2v.apiKey`；draft仅存schemaVersion2、非秘密连接引用和表单内容。不把旧浏览器Key自动上传到服务端；迁移后提示重新配置。

临时connection_id重启后失效：草稿保留选择，但显示“连接已失效，请重新绑定”，不能回退到全局默认Key。服务端环境连接用于用户需要跨重启保留的场景；本期不建立本地明文密钥仓库。

现有`/api/key/verify`会做实际聊天推理，因此从默认检查流程移除；如以后提供“真实调用验证”，单独二次确认计费与数据发送。本轮不触发该验证。

## 5. 声音区

复用已有声音配置Section，模式随TTS过滤，不把本地参考音频和云voice_id混成同一种字段。

| 路径 | 展示与操作 | 全API门槛 |
| --- | --- | --- |
| 系统音色 | 只列目标TTS支持的音色；标签“字级时间戳支持” | 首版默认路径；不随便选未支持时间戳的音色 |
| 上传录音复刻 | 上传本地资源 → 显示参考文本 → 明确“创建百炼音色，可能计费” | 上传本地不等于已克隆；创建成功才有云资源ID |
| 文字设计 | 输入声音描述 → 明确创建/试听 | 未确认时间戳能力时，不可用于全API光标链路 |
| 已有云资源 | 列已注册的当前连接范围资源；可手动注册已存在的ID | 绑定目标模型、地区、连接范围和时间戳支持状态 |
| 本地参考音色 | 保留preset/upload/default | 使用现有本地Qwen3路线 |
| MiMo文字设计 | 保留旧入口，标“非百炼，生成本地参考音频” | 选择此路线不再宣称百炼全API |

创建音色/试听都是独立、可能计费的动作，不通过切换预设或打开抽屉触发。资源创建进行中锁定重复点击；超时未知不自动重复创建。

录音缺参考文字且API ASR未配置时，错误定位参考文本/ASR字段，用户可填写文字或配置ASR。不会自动启动本地识别。云音色跨连接不能默认共享，换连接后需明确重绑同账号资源或重建。

## 6. 数字人区与时长交互

- 保留当前数字人开关默认值；开启后肖像必填，并展示图片检测状态、后端模式与型号。
- 数字人关闭时肖像可保留在草稿，不做检测/上传，也不阻止任务提交。
- 开启提示固定为：**“数字人单段音频必须小于20秒。长讲解将自动分段并拼接，整页和成片时长不受此限制。”**
- 关闭提示固定为：**“未启用数字人，不施加20秒分段限制。”**
- 默认目标18秒显示为策略说明，不设置可编辑20秒上限。后端响应的policy才是最终依据。
- 课程总时长仍由CoursePanel现有auto/custom及1至180分钟控制，不改成20秒；单页音频不能因为>20秒变成非法讲稿。
- 上传肖像只保存本地素材，不自动调用百炼检测；点击开始云任务时说明将发送肖像/音频，检测属于该云端链路。
- 校验失败明确说明缺肖像、地区、音色、连接或模型参数；不以“已自动跳过数字人”继续任务。

## 7. 提交、审核与任务详情

提交区显示每环节实际配置摘要、按需阶段与计费/数据发送说明。根据已有“生成课件并审核”等按钮语义，仅对当前运行阶段说明发送内容，不把未来配音误说成本次立即调用。

- 主操作保持原有生成/审核工作流；只在本次所需环节校验通过后可提交。
- 创建/审核继续/重跑都带当前明确选定的model_config；历史任务默认使用自己的快照，不继承新草稿配置。
- 任务详情新增折叠的“执行模型”表，展示模型、模式、连接名称、时轴来源、目录时间和分段策略，密钥永不显示。
- 进度显示实际阶段、完成页数/段数及远程状态，不制造虚假完成百分比。未知段数先显示“分析音频中”。
- 数字人进度例：“第3页 · 第2/4段 · 云端生成中”；片段总数合成并分段后才能确定。
- 失败提供“复制脱敏错误”“重新绑定连接”“从失败片段继续”“修改配置后重跑”等对应入口；不能给每种错误同一个重试按钮。
- 云端提交状态不明时显示核对提示，禁用直接再次提交；取消提示可能已有云端任务继续处理/计费。
- 已有SSE重放、断线重连和终态停止沿用，只扩展结构化阶段payload，不新建第二套进度通道。

## 8. 状态矩阵

| 状态 | 表现 | 是否可提交 |
| --- | --- | --- |
| 目录加载 | 当前连接内局部骨架/Loading，不遮住整个表单 | 等待当前必需型号校验；不清空历史选择 |
| 目录为空/刷新失败 | 原因、重试、快照过期提示 | 已支持且配置合法的手动型号可保留未验证标记；不自动换模型 |
| adapter未接入 | 待接入说明/禁选 | 否，不能伪装可用 |
| 凭据缺失/临时连接失效 | 对应连接字段错误 | 需要该连接的本次阶段不可提交 |
| 非本次执行阶段未配置 | 灰色“本阶段不使用” | 不阻止当前阶段；后续继续生成须再校验 |
| 音色时间戳未知 | 音色区兼容警告 | 全API光标链路不可提交 |
| 数字人关闭 | 折叠肖像/数字人模型，无20秒上限 | 按其他环节校验 |
| 数字人开启缺肖像 | 肖像字段错误，顶部汇总定位 | 否 |
| 下线型号 | 显示日期与替代建议，保留历史值 | 新执行不可用；历史产物可浏览 |
| 结构化422 | 对应控件下message + 顶部错误摘要 | 否；保持全部用户输入 |

前端展示的就绪状态必须区分配置合法、目录可见与真实调用结果；无权限/余额只有实际请求时能最终确认。

## 9. 响应式、可访问性与实现落点

- 桌面≥1024px：模型表五列，连接抽屉480px宽；中等屏按现有grid收缩。
- 移动<768px：每环节改为卡片纵排，预设换行，抽屉全宽；不横向滚动518项表格。
- 关闭/加载/错误态保留清晰标签，Tab顺序跟随视觉顺序；抽屉关闭后焦点回到触发按钮。
- Label通过控件关联，错误以aria描述，纯配置检查结果可用aria-live；禁选项同时说明原因。
- 型号ID用等宽字体，说明文字不低于现有辅助文字层级；不得用超小字体塞满五列。
