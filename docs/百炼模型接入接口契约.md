# 百炼模型接入接口契约

日期：2026-10-03。状态：目标接口契约，分阶段实现。P1连接管理、配置校验、任务模型快照与重绑已实现，具体当前接口与限制见`百炼接入P1开发说明.md`；其余协议不可当成已可调用的API。

## 1. 原则与规范来源

- `web/model_config.py`中的Pydantic schema作为唯一规范来源，生成OpenAPI/前端类型；字段统一snake_case，前端局部state可camelCase。
- 请求模型`extra='forbid'`，分环节`parameters`也须使用白名单类型，不能用任意dict绕开约束。
- 同一规范化/校验入口服务创建、审核后生成、重跑、课程规划、音色创建；不要每条路由自己解释模型配置。
- 验证先于目录写入、入队、媒体上传和计费调用。纯检查不创建任务/云资源、不发推理。
- 沿用当前本机/受信LAN的写操作保护，新增写路由必须使用相同保护。此服务不是公开多租户系统，不因增加API就宣称完成用户鉴权。
- 参数错误422带字段名；凭据和带签名URL不返回、不写日志。SSE错误也需经过脱敏。

## 2. 连接与协议

连接非秘密字段存于配置/任务快照；Key仅来自服务端环境或本次服务进程内存。稳定环境连接例如`bailian-default`，临时连接使用服务端生成的opaque ID。

| 连接字段 | 规则 |
| --- | --- |
| provider | bailian或openai_compatible；不泛化未实现厂商 |
| label | 非空用户可读名称，长度≤80 |
| compatible_base_url | HTTP(S)合法基址，不含用户名、密码、查询串/片段；去掉重复斜线 |
| native_http_base_url | 百炼原生HTTP入口，与兼容路径分开 |
| websocket_url | CosyVoice接口的明确WS入口，按地域/工作空间文档配置 |
| api_key | 仅创建/换Key输入，不进入响应、draft、job.json或命令行 |
| source | env或memory，只读 |
| scope_id | 非秘密资源隔离ID；稳定在该配置连接范围内，不由Key内容hash生成 |
| readiness | 格式配置、目录读取、各协议配置状态；不宣称推理成功 |

已知兼容基址：`https://llm-3p2iijyqd4hu17zi.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`。

同主机原生目录`/api/v1/models`上轮已读取成功，但不能把目录成功等同于所有原生推理/上传/WebSocket都验证成功。首版分别配置兼容、原生HTTP、WS；原生HTTP可展示同主机`/api/v1`候选，确切推理/上传/WS路由必须在P4/P7依据官方SDK/工作空间文档确认后置为支持。没有WS有效配置时CosyVoice不是就绪状态，不偷偷使用公网默认端点。

安全地址规则：百炼限制到服务器认可的HTTPS/WSS百炼主机；本地兼容地址只允许loopback及部署者显式配置的私网服务。拒绝元数据地址、用户信息、非白名单重定向；媒体下载同样校验域名/重定向、限大小/超时。云端无法访问localhost，禁止把本地URL当Wan输入URL。

### 2.1 连接路由

| 方法/路由 | 请求与返回 |
| --- | --- |
| GET /api/model-connections | 返回连接ID、标签、source、scope_id、协议基址、key_present、readiness；无Key |
| POST /api/model-connections | 严格ConnectionCreate；创建瞬时连接，201返回非秘密快照；只做格式/安全校验 |
| PATCH /api/model-connections/{id} | 只更新明确提供的字段；换Key可保持同scope但须确认资源仍归同账号；改变账号明确新scope |
| DELETE /api/model-connections/{id} | 只删除memory连接；有运行任务引用则409；不删除历史产物/云端音色；env连接不可从此删除 |

创建/换Key后由前端清空密码输入。重启丢失memory凭据，GET返回该草稿连接不可解析状态；既有任务可读取，恢复运行须重绑。历史任务不能自动使用另一个连接的Key。

不向用户承诺服务端能仅凭Key判断账号相同；scope是受信配置隔离边界，不是已验证云账号身份。换账号资源须重新注册/核验。

          "model": "cosyvoice-v3.5-plus",
          "parameters": {"speech_rate": 1.0}
        },
        "asr": {
          "mode": "api",
          "provider": "bailian",

        },
        "grounding": {
          "mode": "api",

### 3.1 组合约束

- `schema_version=2`；`preset=bailian_api|local_existing|custom`。preset只是快捷标签，实际模式由有效配置判断，禁止用标签绕过逐环节校验。
- text/vision：api+bailian或api/local+openai_compatible；local须受信本地服务连接，并不自动加载权重。
- tts/asr：api+bailian或local+qwen3。local模型ID使用现有明确安装型号/模型路径配置映射，不允许浏览器指定任意文件路径。
- grounding：api+bailian或local+gui_owl；本地模型路径由服务端维护。
- avatar：api+bailian+wan2.2-s2v或local+musetalk；detect模型由适配器绑定，不向用户暴露可随意替换的检测ID。
- timing：tts_timestamp要求支持时间戳的API TTS/音色；local_forced_aligner明确本地依赖。当前没有api_forced_aligner这个可执行选项。
- local专用模型无connection_id（null/省略）；兼容本地服务仍必须有连接。实际必需API阶段必须有可解析的connection_id。
- avatar.enabled=false时不校验肖像/数字人凭据就绪，也不执行其分段；保留字段供重新启用，但仍做基础类型/字段合法性检查。
- ASR仅在确实需要识别参考录音且没有参考文本时成为执行依赖；不让可选ASR阻止不使用它的任务。
- 分环节参数只开放已实现且有模型约束的字段，如speech_rate。词级时间戳开关、输出音频可对齐格式、20秒策略由后端固定，不允许客户端关闭/覆写关键条件。
- 运行阶段仍用现有config.stages的1/2/3表示；与model_config.stages中的角色不同，不能互相覆盖。

### 3.2 后端派生policy

开启：`{"avatar_enabled":true,"max_segment_seconds_exclusive":20,"target_segment_seconds":18,"policy_version":1}`。

关闭：`{"avatar_enabled":false,"max_segment_seconds_exclusive":null,"target_segment_seconds":null,"policy_version":1}`。

这是validate和job快照的只读结果，不是允许客户端传入的控制字段。后端实际校验使用采样数，不直接比较浮点展示值。

## 4. options、目录与纯配置校验

### 4.1 GET /api/options（扩展）

保留原字段，新增model_schema_version、presets、role_options、adapter_capabilities、constraints、voice_capabilities。由schema/已实现适配器生成，不手写另一套模型规范。

每项能力明确：implemented、protocol、regions、supports_word_timestamps、coordinate_scheme及生命周期状态。不支持的能力用false/unknown区分，不填乐观默认true。

### 4.2 POST /api/models（扩展）

v2请求`{connection_id,role,include_retiring:false,cursor:null,limit:100,refresh:false}`，role限定text/vision/tts/asr/grounding/avatar。响应：

```json
{
  "schema_version": 2,
  "items": [{
    "id": "qwen3-vl-plus",
    "roles": ["vision", "grounding"],
    "protocols": ["openai_compatible_chat"],
    "adapter_implemented": false,
    "status": "active",
    "verification": "catalog_only"
  }],
  "next_cursor": null,
  "catalog_time": "2026-10-02T23:11:03+08:00",
  "source": "workspace_snapshot",
  "warnings": []
}
```

例中的adapter_implemented=false表示尚未实现的本轮现状。实现后按代码能力实际更新，不通过静态目录自动置true。

兼容与原生目录按ID合并、记录各自来源，不认定互相包含；完整读取原生分页，去掉当前500条静默截断。服务端缓存目录并按环节/生命周期过滤后分页给前端，游标与连接/查询指纹绑定；limit限定1至100。refresh只是模型目录GET，非推理。

旧`{api_key,api_base}`请求暂时沿用旧响应给旧前端，输入只进入内存，记录弃用警告；新前端不再使用。禁止把legacy/v2字段混合成两个来源。

### 4.3 POST /api/model-config/validate（新增）

请求：`{model_config,voice,portrait_path,reference_text,requested_stages}`；路径必须来自本服务上传/ingest资源，不能任意文件路径。requested_stages按现有阶段定义。

校验包括schema、provider/mode协议组合、适配器是否实现、连接、已知目录下线、音色目标/时间戳/范围、条件肖像、参数及实际执行依赖。此接口不识别录音、不检测图片、不合成、不验证推理权限。

200返回：normalized_model_config、effective_mode、required_roles、inactive_roles、derived_policy、warnings、validation_level=`configuration_only`。可列出本次可能发生的远程操作类别，不伪造价格或精确总调用次数。

422返回字段问题，格式见第8节。请求字段变化即失效前端“检查通过”标记；实际执行前后端仍必须再次校验，不能信任前端状态/校验token。

## 5. 任务、审核、重跑与课程

不新建第二套工作流，扩展以下现有路由，并保持现有创建任务200响应兼容。

| 路由 | v2改动 |
| --- | --- |
| POST /api/jobs | config.model_config及扩展voice；服务端规范化后再入队；返回effective_mode/derived_policy及现有job信息 |
| POST /api/jobs/{id}/review/run | 默认用该任务快照；允许显式替换配置并校验，展示下游缓存变化 |
| POST /api/jobs/{id}/prepare-retry | 不推理、不上传；整理可复用清单与未完成片段，禁止直接删除共享产物 |
| GET /api/jobs/{id}/rerun-plan | 返回各阶段复用/失效原因与有效模型快照，不只返回单个全局model_api_base |
| POST /api/jobs/{id}/rerun | 同schema；变更只失效依赖阶段；按任务级写入所有权排队 |
| 原有课程规划路由 | 必须接收/解析text角色配置，不回退旧全局Key；课件后生成同样使用任务快照 |
| 既有任务读取/产物路由 | 扩展执行模型、时间戳/分段manifest；继续可读旧任务 |
| 既有取消路由 | 停止后续提交，维护remote_cancel状态；不把本地取消等同云端取消成功 |

v2创建/重跑/云音色计费动作使用`Idempotency-Key`（客户端每次明确动作生成UUID）。同键同规范化输入返回原任务/资源状态；同键不同输入409。Key在既有任务/资源manifest持久化索引范围内防重，不能只靠页面按钮锁或进程内map。键的保留期须覆盖该资源可重试期，不宣称供应商也支持该键。

云提交未知另有submission_unknown状态，HTTP应用层防重不能替代供应商受理核对。legacy请求保持旧兼容行为，不承诺旧调用天然防重复计费。

临时连接凭据失效时返回connection_expired，并提供明确重绑入口：`POST /api/jobs/{id}/model-connections/rebind`，请求为原connection_id到新connection_id映射；保持模型/素材等快照，只重新校验资源scope。接口不直接重新提交远程任务，重绑后须显式继续；不能隐式绑定到全局默认连接。

新增`POST /api/jobs/{id}/remote-tasks/reconcile`用于用户明确核对已知task_id状态并归档已完成结果。仅查状态/下载，不提交新生成；未知ID不假设供应商可按幂等键查到，返回needs_manual_review，需用户提供可核实远程记录后再决定是否重试。

### 5.1 兼容迁移

- 没有model_config则按原text_model/vision_model/api_base及现有本地路线生成legacy有效快照，保持行为，不自动选百炼。
- 新v2请求不得同时提供冲突的text_model/vision_model/generate_talking/api_key/api_base；两套控制源冲突时422，而非优先级猜测。
- legacygenerate_talking迁移后为avatar.enabled；v2CLI需要旧参数时从新配置派生，不在job中维持两个可编辑真值。
- 接口迁移完成后逐步弃用legacy字段，旧job.json仍有读兼容。不要把缺失配置解释为全API默认。

## 6. 音色与本地上传

P4实施差异：百炼音色采用独立`/api/cloud-voices`命名空间，避免与旧MiMo的`/api/voices/generate`混用。当前已实现GET目录、POST register/generate、POST资源refresh/preview及GET已归档sample；创建/试音需要持久化Idempotency-Key。系统音色白名单、设计时间戳门禁、私有OSS复刻配置和请求schema以`百炼接入P4开发说明.md`及实际OpenAPI为准。下表仍描述总体目标，不表示可选API ASR及P7/P8接口已经实现。

| 路由 | 契约 |
| --- | --- |
| POST /api/voices/upload | 保持本地上传；限字节/时长、按实际内容识别格式/解码，不只看扩展名；返回本地资源，不自动创建云音色 |
| POST /api/voices/generate | 扩展严格voice请求，明确provider/connection_id/kind/target_model；云clone/design由用户主动触发；旧MiMo请求保留但明确legacy |
| POST /api/voices/register | 新增：注册已存在云voice_id到当前连接范围，不推理；仅根据用户声明不能标成已经验证可用 |
| GET /api/voices | 扩展/新增当前连接范围音色列表；返回system/cloud/local、目标模型与时间戳能力三态 |
| GET /api/voices/{key}/sample | 保留本地已归档试听音频；取已有结果不再触发隐式计费合成 |

云请求包含kind=clone|design，clone引用本服务上传音频，design提供描述；不接受前端任意外部URL。成功保存资源ID、目标型号、地区、scope、时间戳状态和创建结果，不保存Key/签名。system音色也注册成可引用的非秘密资源记录，避免与云创建ID混淆。

音色创建未知状态与生成任务一样防重复；试音如需要另一次合成，必须在UI明确说明，不能挂在GET sample后隐式执行。云资源是否删除/额外计费遵循当前官方接口；本地删除引用不等于已删云音色，首版不擅自做云资源删除。

## 7. pipeline产物与状态

保留`audio/<zero-based-page>.wav`、现有逐页/最终视频与`merge_video.mp4`消费布局；前端页号仍1起计数。新增sidecar/manifest不改变老下载入口。

### 7.1 音频与时间戳

`audio/<page>.timing.json`示例：

```json
{
  "schema_version": 1,
  "source": "tts_timestamp",
  "audio_sha256": "example_hash",
  "script_sha256": "example_hash",
  "sample_rate": 24000,
  "sample_count": 720000,
  "time_unit": "seconds",
  "time_origin": "page",
  "segments": [{"words": [{"word": "示例", "start": 0.10, "end": 0.65}]}]
}
```

采样率为示例，不硬编码所有模型都输出24k。另保存原文/规范化映射及分块参数；时值须非负、单调、落在实际音频范围，原稿映射完整。缺wav、hash不匹配、时间轴不完整均不算可复用缓存。

既有audio/manifest.json增加mode/provider/model/scope/voice/resourcehash/parameters/timing版本字段。关键配对产物写临时文件，全部校验后最后更新manifest有效指针；中途失败不可留下貌似完整的缓存。

### 7.2 数字人片段

页级`avatar_segments.json`：policy_version、avatar_enabled、page_audio_sha256、sample_rate、segments。每段包含segment_index、start_sample、end_sample_exclusive、start_sec/end_sec、text范围、audio_sha256、avatar模型/肖像hash、status、remote_task_id及request_id。

- 样本区间连续无重叠，覆盖整页，无重复插入静音；每段`end_sample_exclusive-start_sample < 20*sample_rate`。
- 数字人关闭时不创建带20秒限制的片段manifest，也不因历史长页拒绝运行。
- 签名输入/输出URL只在瞬时内存使用；task_id和脱敏请求ID可持久化。远程响应只取字段白名单，不能整包写日志。
- 切换数字人模式仅重建对应派生产物；结果指针隔离任务/重跑所有权，禁止递归清空共享目录。

### 7.3 SSE与远程状态

保留现有事件名、序号和重放机制，扩展payload：role、mode、model、page_index、segment_index、completed_segments、total_segments、remote_status、request_id。单个事件不能含Key、Authorization、带签名URL或完整音频/图像base64。

远程状态规范化为preparing_media、checking_portrait、submitting、submission_unknown、queued、running、downloading、merging、succeeded、failed、cancel_requested、cancelled、cancel_unconfirmed。供应商返回字段与本地状态映射分开保存，未知值不能直接视为成功。

仅有total_segments时展示比例；音频尚未生成时不估造百分比。网络重试用于目录GET、已知task_id查询/下载，指数退避有上限；有计费副作用的提交不得泛用自动重试。

## 8. 错误结构、限流与安全

422统一格式：

```json
{
  "detail": {
    "code": "invalid_model_configuration",
    "problems": [{
      "field": "config.model_config.avatar.enabled",
      "message": "已开启数字人，请上传肖像或关闭数字人。"
    }],
    "request_id": "local_request_example"
  }
}
```

内部错误映射到完整前端字段路径；`flow.ts`同时兼容旧字符串detail、FastAPI验证数组和新problems对象。字段路径只指向可操作字段，不能把密钥原值拼进message。

| 情况 | HTTP/任务错误码 | 用户操作 |
| --- | --- | --- |
| schema/组合/缺资源 | 422 invalid_model_configuration | 定位字段修正 |
| 缺失或重启丢失凭据 | 409 connection_expired | 重绑连接，不换模型 |
| 本应用访问边界不通过 | 403 write_not_allowed | 使用本机/受信来源；fail-closed |
| 云端Key拒绝 | 同步502 provider_auth_failed，异步任务同码 | 核对账号/Key；不是假装本应用用户登录失效 |
| 无模型权限/额度 | provider_permission_denied / provider_quota_exceeded | 用户处理平台权限/额度，不自动降级 |
| 远端限流 | 同步429 provider_rate_limited | 按Retry-After/上限退避，禁止无限循环 |
| 重复键不同内容/共享写冲突 | 409 idempotency_conflict / artifact_in_use | 显式新操作或等当前任务 |
| 正好20秒或更长的数字人输入 | 422 avatar_segment_too_long | 自动重新分段；仍不可满足则停下 |
| 无时轴/无法映射原稿 | timing_unavailable / timing_text_mismatch | 更换兼容音色或显式改混合模式 |
| 提交是否受理不明 | submission_unknown | 核对远端任务，不直接再次计费提交 |
| 上传/模型协议未实现 | 422 adapter_not_implemented | 阻止该选择，不用假实现继续 |

同步provider错误只用于仍在请求内执行的操作；入队后的错误通过任务状态/SSE返回，不伪造原创建请求HTTP状态。

限制敲定：新模型JSON≤256KiB，单连接请求≤16KiB，模型limit≤100；远程调用均有连接/读取超时，SSE保留现有限制。音频/肖像沿用更严格的现有限额并加入provider约束，Wan音频<15M；精确格式/像素/字节及音色上传时长取适配器规范，不凭空统一成一个数。

任何上传/下载解码失败422并清理本次临时文件，不留下孤儿任务；不能删用户源文件或其他任务目录。保留原子写入/路径边界和受信写保护，新增连接/voice/rebind/reconcile请求均纳入body limit与保护。

SDK日志关闭原始headers/URL输出，脱敏必须覆盖正常/异常/debug路径。Key不进Git、目录快照、job.json、audio manifest、SSE、localStorage或CLI argv。用户此前已在聊天中提供Key；实施前建议在平台轮换并改为环境变量/临时配置，不在文档复述该值。
