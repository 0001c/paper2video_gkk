# C1 · 8分钟微课讲稿

## 1. 从损失到参数更新

我们面对的核心问题很具体：网络当前的参数w，不知道自己该往哪调，才能让预测误差——也就是损失J(w)——变小。

训练的第一步是初始化参数w，接着用它做前向预测，算出当前输出；再和真实值比较，得到损失J(w)。此时我们手头只有J和w，没有其他信息——所以更新必须只依赖当前位置的局部信息。

关键动作来了：我们沿着损失下降最快的方向走一小步。数学上，这个方向就是负梯度：-dJ/dw。注意，dJ/dw是损失对参数的导数，不是参数对损失的导数——导数符号反了，方向就全错了。

于是参数更新公式是：w_new = w - eta * dJ/dw。这里eta必须大于0，它控制步长大小；负号确保我们朝损失减小的方向走。

举个简单例子：若当前dJ/dw = +3，说明w增大时损失上升，那我们就该减小w——公式里减去正数，正好实现w变小；若dJ/dw = -2，说明w增大时损失下降，我们就该增大w——减去负数，等价于加上正数，w自然变大。

一个常见错误是把公式写成w + eta * dJ/dw。只要记住：导数为正，损失随w增大而增大，我们就得让w减小；导数为负，损失随w增大而减小，我们就该让w增大。统一用‘减’号就能覆盖两种情况。

现在你已经看到：从损失出发，我们通过求导获得方向，再用学习率缩放步长，最终完成一次参数更新。下一页，我们将深入讨论：这个步长eta到底多大合适？为什么有时走着走着反而震荡起来了？

## 2. 学习率与优化边界

上一节我们得到参数更新公式：w_new = w - η · dJ/dw。负梯度 -dJ/dw 指出当前点损失下降最快的局部方向——但它只回答‘往哪走’，没回答‘走多远’。

这个‘走多远’由学习率 η 控制，它是一个正数，决定每次更新的步长大小。

如果 η 过小，比如 0.001，每一步挪动极微，收敛像蜗牛爬坡；如果 η 过大，比如 1.0，可能一步跨过谷底，下一次又跳到对面山坡，造成震荡，甚至越跑越远、彻底发散。

这里必须强调：负梯度只保证局部下降，不保证全局最优。因为神经网络的损失函数通常是‘非凸’的——就像有多个山谷的地形，算法可能停在某个局部低点就以为到了最低处。

举个教学例子：假设你站在山腰，只能感知脚下斜率，于是朝下坡迈一步。但你不知道前方有没有更深的谷，也不知道这一步该迈半米还是两米——迈太小耗时，迈太大可能踩空滚回高处。这就是学习率需要谨慎选择的原因。

接下来我们会看到，反向传播负责算出这个梯度 dJ/dw，而优化器才用它来更新参数——求导和更新是两个独立环节，不能混为一谈。

## 3. 反向传播负责计算梯度

上一节我们确定了：参数更新的方向由负梯度决定，步长由学习率控制；但梯度本身从哪里来？这正是本环节要解决的核心问题。

训练神经网络时，我们无法直接观测‘损失对某个权重的敏感度’——它被层层计算隐藏起来了。反向传播就是专门负责把这个隐藏的梯度‘挖’出来的机制。

整个训练流程被清晰地拆成三个阶段：前向传播走一遍输入 → 预测 → 损失；接着反向传播从输出回传局部导数；最后优化器使用梯度更新参数。

特别注意：求梯度与参数更新是两个独立环节。就像测绘员先测出坡度，推土机才据此决定推多远——测量结果不等于动作本身。

反向传播的具体任务是：从损失输出端开始，沿着计算图反向传递局部导数，最终得到每个可训练参数对损失的偏导，也就是梯度。

举个教学小例子帮助理解：设损失 e = (a + b)(b + 1)，其中 a、b 是待调参数；我们先算中间量 c = a + b、d = b + 1，再得 e = c·d。

反向时，从 e 出发：∂e/∂c = d，∂e/∂d = c；再回传到 c 和 d，分别乘上它们对 a、b 的导数。关键易错点：b 同时影响 c 和 d，它的总梯度是两条路径贡献之和，不是乘积。

这种分工极大提升效率——一旦中间变量的导数被算出，就能被多个上游节点复用，避免重复展开整条链。下一页我们将用这个例子完整走一遍计算过程。

## 4. 链式法则与中间结果复用

当我们计算一个复合函数对某个输入变量的导数时，比如e = (a+b)(b+1)，变量b并不只走一条路影响e——它既通过c = a+b，又通过d = b+1，最终汇入e。这时，链式法则必须处理‘路径’这个结构。

沿同一条路径，局部导数要相乘。例如从e到c再到a：e ← c ← a，那么∂e/∂a = (∂e/∂c) × (∂c/∂a)。

而当多个路径汇向同一个变量，比如b同时连到c和d，再共同影响e，就必须把每条路径的贡献加起来：∂e/∂b = (∂e/∂c)(∂c/∂b) + (∂e/∂d)(∂d/∂b)。

这里的关键是中间导数可以复用。一旦算出∂e/∂c和∂e/∂d，所有上游变量——a、b——都能直接调用它们，避免重复展开整个表达式。

这种模式特别适合多个输入、单个标量输出的情形，比如神经网络的损失函数：它接收大量权重作为输入，但只输出一个数值。反向传播正是利用这一结构高效求出全部梯度。

下一页，我们就用教材这个具体例子e=(a+b)(b+1)，代入a=2、b=1，严格按路径相乘、分支相加、中间复用三步，算出∂e/∂a=2、∂e/∂b=5——尤其注意b的两条路径，漏掉任何一路，梯度就错了。

## 5. E1：教材计算图逐步求导

我们来完整走一遍教材中的计算图求导过程，它直接体现反向传播如何处理共享变量的多路径影响。

给定表达式 e = (a + b) * (b + 1)，其中 a = 2，b = 1。先做前向计算：令 c = a + b = 3，d = b + 1 = 2，那么 e = c * d = 6。

现在从输出 e 往回求局部导数：e 对 c 的偏导是 de/dc = d = 2；e 对 d 的偏导是 de/dd = c = 3。

输入 a 只通向 c，再由 c 通向 e，路径唯一，所以 de/da = (de/dc) × (dc/da) = 2 × 1 = 2。

而 b 不同：它同时参与生成 c 和 d，因此有两条独立路径影响 e。

第一条路径 b → c → e 的贡献是 (de/dc) × (dc/db) = 2 × 1 = 2；第二条路径 b → d → e 的贡献是 (de/dd) × (dd/db) = 3 × 1 = 3。

最终 ∂e/∂b 是两路贡献之和：2 + 3 = 5。这里的关键易错点是——多路径必须相加，绝不能相乘，也不能遗漏任一路径。

## 6. 串联训练流程与检查理解

现在我们把整套训练流程串起来：给定初始参数，先做前向计算得到预测输出；接着用真实标签算出损失；然后从损失反向求各参数的梯度；最后用负梯度方向乘以学习率来更新参数。

注意，反向传播只是高效计算梯度的手段，它本身不执行更新——更新是独立的一步，由公式 w_new = w - η·∂J/∂w 完成。梯度下降是‘求导+更新’的组合动作，不能把反向传播等同于整个优化过程。

在计算梯度时，链式法则体现为：同一路径上的局部导数要相乘，比如 b→c→e 这条路，贡献是 ∂e/∂c × ∂c/∂b；而当一个变量如 b 同时影响多个中间节点（c 和 d），这些路径的贡献必须相加，不能相乘，也不能遗漏。

学习率 η 是正数，它控制每一步的步长：太小会导致收敛缓慢；太大可能越过极小值、震荡甚至发散。更要紧的是，神经网络的损失函数通常是非凸的，这意味着梯度下降只能找到局部最小值，无法保证全局最优。

我们回头检查关键疑问：为什么 b 的偏导要包含两路？因为在计算图中，b 同时输入到 c = a + b 和 d = b + 1，再共同影响 e = c·d；所以 ∂e/∂b = ∂e/∂c·∂c/∂b + ∂e/∂d·∂d/∂b = 2×1 + 3×1 = 5。漏掉任一路，结果就错了。
