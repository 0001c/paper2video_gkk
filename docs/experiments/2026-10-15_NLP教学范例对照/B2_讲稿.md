# B2 · 8分钟微课讲稿

## 1. 从损失到参数更新

我们面对的核心问题是：网络参数怎么知道该往哪改，才能让预测误差变小？

答案是沿着损失函数下降最快的方向走一小步——这个方向就是损失对参数的负梯度。

具体操作分三步：先初始化参数，再前向传播得到预测值，最后用真实标签算出损失J(w)。

关键更新公式是 w_new = w - eta * dJ/dw。

这里eta必须大于0，它叫学习率，控制步长大小；dJ/dw不是w对J的导数，而是损失J对参数w的偏导，表示当前点损失随w变化的陡峭程度。

为什么是减号？因为梯度指向上升最快方向，负梯度才指向下降最快方向——就像球在山谷里自动滚向低处。

注意：求导（算dJ/dw）和更新（用它改w）是两个独立环节；反向传播负责前者，更新公式执行后者。

接下来我们会看到，当一个参数通过多条路径影响损失时，它的总梯度是各路径贡献之和，不能漏掉任何一条。

## 2. 学习率与优化边界

上一节我们得到参数更新公式：w_new = w - η · ∂J/∂w，其中负梯度 -∂J/∂w 指出损失函数在当前位置下降最快的方向。

但方向只是第一步；真正决定优化效率的，是每次迈多大步——这由学习率 η 控制，它必须是正数，用于缩放梯度的幅度。

η 过小，更新步长太短，就像在陡坡上挪动脚尖，即使离谷底很近，也要迭代成千上万次才能收敛；η 过大，一步跨得太远，可能直接越过最低点，甚至在山谷两侧来回反弹，导致震荡或彻底发散。

更需注意的是，神经网络的损失函数通常是高度非凸的，地形像布满山丘与洼地的高原。梯度下降只能保证找到‘当前位置附近最低的坑’，即局部最优解，无法确保那是全局最低点。

因此，负梯度提供局部下降方向，学习率调节步长大小，二者协同工作；但无论怎样调整，算法本质仍是基于局部信息的贪心搜索——它不回头看，只向前试探。

那么问题来了：这个关键的梯度 ∂J/∂w 是怎么算出来的？它不是凭空出现的；下一节我们将看到，反向传播正是负责从输出误差回传、逐层计算这些偏导数的机制。

## 3. 反向传播负责计算梯度

上一节我们确定了：负梯度给出局部下降最快的方向，学习率控制步长大小——但这些都依赖一个前提：梯度本身必须先被算出来。

现在我们聚焦训练流程的分工：前向传播负责从输入到预测、再到损失的计算链条。

而反向传播专责从输出端回传局部导数，逐层解析每个中间结点对最终损失的敏感程度。

优化器则接收这些梯度，执行参数更新：w ← w − η·∇J(w)。

特别注意：求梯度与参数更新是两个独立环节。就像医生先做CT扫描（反向传播得梯度），再开处方用药（优化器更新参数）；不能把扫描图像直接当成药方。

为什么需要这种分工？因为神经网络的计算图可能包含成千上万个参数，直接对每个参数求偏导会爆炸式重复计算；反向传播通过链式法则复用中间导数，高效得出全部梯度。

下一页，我们将用教材例题 e = (a + b)(b + 1) 展示：一条路径上局部导数相乘，b 经 c 和 d 两条路径影响 e 时，贡献必须相加——这是易错核心。

## 4. 链式法则与中间结果复用

现在我们面对一个关键问题：当一个变量通过多个中间节点影响最终输出时，它的总梯度该怎么算？比如在神经网络里，某个权重可能同时参与多个激活计算，最终汇入同一个损失值。

链式法则在单条路径上很简单：局部导数相乘。例如从输出e回传到中间变量c，再传到输入a，就是∂e/∂c × ∂c/∂a。

但现实更常见的是分支结构——像变量b既进入c = a + b，又进入d = b + 1，最后e = c × d。这时b对e的影响必须把两条路径的贡献加起来：∂e/∂b = ∂e/∂c·∂c/∂b + ∂e/∂d·∂d/∂b。

注意：不能把两个路径的导数相乘，也不能只取其中一条。漏掉任一路径就会导致梯度错误，训练就可能失效。

幸运的是, 中间导数如∂e/∂c和∂e/∂d一旦算出，就能被所有依赖它的输入共享使用——这就是‘复用中间导数’的核心价值。

试想：若对每个输入都重新展开整个计算图，我们会反复计算相同的子表达式；而反向传播一次遍历就复用这些结果，大幅节省计算量。

这种模式特别适合‘多个输入、标量输出’的情形——神经网络的损失函数J正是标量，而成千上万个权重是输入。反向模式因此成为深度学习的标准选择。

## 5. E1：教材计算图逐步求导

我们来解这个计算图求导的典型例子：e = (a + b) × (b + 1)，其中 a = 2，b = 1。

先做前向计算：令 c = a + b = 3，d = b + 1 = 2，于是 e = c × d = 6。

从输出 e 反向推局部导数：e 对 c 的偏导是 d，即 2；e 对 d 的偏导是 c，即 3。

接着用链式法则求输入偏导：a 只通过 c 影响 e，所以 ∂e/∂a = (∂e/∂c) × (∂c/∂a) = 2 × 1 = 2。

而 b 同时进入 c 和 d 两条路径：经 c 贡献 (∂e/∂c)(∂c/∂b) = 2 × 1 = 2，经 d 贡献 (∂e/∂d)(∂d/∂b) = 3 × 1 = 3，总和为 5。

注意：b 经过两条路径影响 e；不要漏项——这是反向传播的核心规则，多路径贡献必须相加，绝不能相乘或忽略任一通路。

## 6. 串联训练流程与检查理解

现在我们把整套训练流程串起来：前向计算得到预测值，用真实标签算出损失，再反向求梯度，最后用梯度更新参数。

注意，反向传播只是求梯度的过程，它不等于梯度下降；更新动作是独立的一步，由学习率控制步长。

在计算图中，同一路径上的局部导数要相乘，比如从b到c再到e，贡献是∂e/∂c × ∂c/∂b；而当b分出两条路径——一条经c、一条经d——影响同一个输出e时，这两路贡献必须相加，不能相乘也不能遗漏。

学习率η是一个正标量，太小会让更新缓慢，太大则可能跳过极小点甚至发散；更要紧的是，神经网络的损失函数通常是非凸的，梯度下降只能保证找到局部最小，无法保证全局最优。

我们回头检查一个关键理解点：为什么b的偏导要包含两路？因为在e=(a+b)(b+1)中，b既出现在第一个因子(a+b)里，又出现在第二个因子(b+1)里，相当于它通过c和d两个中间节点共同影响e，所以∂e/∂b = ∂e/∂c·∂c/∂b + ∂e/∂d·∂d/∂b = 2×1 + 3×1 = 5。
