## 关键结论

1. 百炼 CLI 是调用云端能力的命令行入口，不是全链路生成引擎，也不会自动给本项目增加前端切换。
2. 已核实 CLI 有 `bl text chat`、`bl vision describe`、`bl speech synthesize`、`bl speech recognize` 和视频任务生成/查询/下载入口。
3. 百炼云端 API 除普通 TTS 外，也提供声音复刻和声音设计；创建音色与消费音色是两步。CLI 的 speech 命令清单没有独立音色复刻/设计创建命令，不能因为 synthesize 支持 voice ID 就声称它已封装音色创建全流程。
4. 官方视觉理解文档明确支持 Box/Point 定位，可作为 GUI-Owl 的云端候选，但必须针对课件文字、公式、图表校验定位效果和返回协议。Qwen3-VL 等系列归一化坐标是 [0,999]，现有 GUI-Owl 契约是 0-1000，不能直接假定所有型号坐标相同。
5. 官方录音文件识别文档支持句子/词语级时间戳，能够构建云端字幕和光标时间轴；但 ASR 的识别文字及时间戳不等于给定原始讲稿的强制对齐。当前 timesteps 按有效字符数映射，对识别文本与讲稿的差异敏感。精确保持 ForcedAligner 语义时，本次未确认 CLI 或百炼存在可直接一比一替换的专用公开接口；需要单独的远程对齐服务或明确实现文本匹配及误差策略。
6. 官方 LivePortrait API 支持肖像图片与指定人声音频生成人像视频，可作 MuseTalk 的云端候选；无需用普通文生视频假装精准口型同步。当前 CLI 视频命令清单没有独立 LivePortrait / detect 命令，应使用其原生 API 或另行封装，而不是随意给 video generate 填 model 就声称支持。
7. LivePortrait 官方文档限制华北2（北京）地域与对应 API Key；输入图片须先通过检测，输入媒体使用可访问 URL，音频时长大于1秒且小于3分钟、体积小于15MB，结果 URL 有时效（文档为24小时）。实现时需要上传、轮询、下载、长页分段和音轨/时长检查，不能认为与本地 MuseTalk 输出完全一致。
8. 综上：可用百炼作为主要云端模型提供方构建全 API 推理路径，但不能承诺只安装 CLI 就完整覆盖现有功能或完全保持精确对齐等价。建议应用后端直连 HTTP/SDK，CLI 用于人工配置和调试；如果选 CLI 后端也可以，但须固定命令、隔离任务配置、处理 JSON 与异步任务，不能让用户输入拼接任意 shell 命令。

## 下一阶段实现边界

- 前端提供一键 API 优先/本地优先预设与逐环节 mode、provider、model、endpoint 设置；预设只能选择实际已实现且可用的后端。
- 保留现有 Qwen3-TTS/ASR/ForcedAligner、GUI-Owl、MuseTalk 路径；文本/视觉的本地模式可走本地兼容模型服务，不把 HTTP 与本地推理混为一谈。
- 区分配音、音色创建、转写、时间轴/强制对齐、光标定位、数字人协议，不把所有服务当成聊天 API。
- 普通内置音色直接配音，自定义上传音色先复刻，文字设计音色先创建；缓存/任务保存 voice ID 时需要绑定提供方与目标模型。
- 全 API 模式下不得静默回退加载本地 GPU 模型。时间戳方案需要在界面注明是否严格强制对齐，不能把按字符均分冒充精确同步。
- 密钥只留后端，不写到 job.json、日志或前端持久化；缓存与任务快照区分模式、提供方、模型、端点和音色。
- 保留本地 LaTeX 编译、PDF 渲染、FFmpeg 合成、队列、缓存、人工审核等非模型步骤；所有模型走 API 不等于所有计算完全上云。
- 用户仍明确不要冒烟测试。下一步即使实现代码，也不得擅自真实付费调用或执行冒烟任务。
