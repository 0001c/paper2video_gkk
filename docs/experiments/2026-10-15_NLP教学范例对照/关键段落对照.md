## 第1页：从损失到参数更新

### A

我们今天要解决的核心问题是：如何让神经网络的预测越来越准？

答案藏在损失函数 J(w) 里——它量化了当前参数 w 下预测与真实值的差距。

训练不是靠猜，而是一套闭环流程：先初始化参数，再前向传播得到预测，接着计算损失，最后根据损失对参数的敏感程度来调整参数。

关键一步是参数更新公式：w_new = w - eta * dJ/dw。

这里 eta 必须大于 0，它叫学习率；dJ/dw 不是 w 对 J 的导数，而是损失 J 对参数 w 的导数——方向错了，整个更新就反向奔向更高损失。

为什么减号？因为负梯度指向损失下降最快的方向，就像球沿山坡滚向谷底。

注意：求导（反向传播）和更新参数是两个独立环节——前者算出‘该往哪走’，后者决定‘迈多大步’。

接下来我们会用教材第15页的例题 e = (a+b)(b+1) 来亲手推导偏导，看清 b 如何通过两条路径影响 e，避免漏项或误乘。

### B

我们面对的核心问题很直接：神经网络的参数w一开始是随机的，预测结果和真实值差距很大，损失J(w)很高；参数该怎么改，才能让损失一步步变小？

答案是沿着损失下降最快的方向走一小步——这个方向就是负梯度方向。数学上，我们用更新公式 w_new = w - eta * dJ/dw 实现它。

这里eta必须大于0，它叫学习率，控制我们每次迈多大步；dJ/dw不是w对J的导数，而是损失J对参数w的导数，也就是当前点的斜率。

为什么是减号？因为导数dJ/dw为正时，说明w增大让损失变大，那我们就该减小w；导数为负时，w增大让损失变小，我们反而要增大w——统一写成减去正的学习率乘以导数，就自动实现了‘往低处走’。

整个流程是四步闭环：先初始化参数，再前向预测得到输出，接着计算损失J(w)，最后用梯度信息更新参数。

注意，计算导数和执行更新是两个独立步骤，不能混为一谈；导数告诉我们‘该往哪走’，更新公式才真正执行‘迈步’动作。

本页目标是建立‘损失→导数→更新’的因果链：损失告诉我们有多错，导数告诉我们错的方向和陡峭程度，更新则把这一信息转化为参数的实际调整。

### C

我们面对的核心问题很具体：网络当前的参数w，不知道自己该往哪调，才能让预测误差——也就是损失J(w)——变小。

训练的第一步是初始化参数w，接着用它做前向预测，算出当前输出；再和真实值比较，得到损失J(w)。此时我们手头只有J和w，没有其他信息——所以更新必须只依赖当前位置的局部信息。

关键动作来了：我们沿着损失下降最快的方向走一小步。数学上，这个方向就是负梯度：-dJ/dw。注意，dJ/dw是损失对参数的导数，不是参数对损失的导数——导数符号反了，方向就全错了。

于是参数更新公式是：w_new = w - eta * dJ/dw。这里eta必须大于0，它控制步长大小；负号确保我们朝损失减小的方向走。

举个简单例子：若当前dJ/dw = +3，说明w增大时损失上升，那我们就该减小w——公式里减去正数，正好实现w变小；若dJ/dw = -2，说明w增大时损失下降，我们就该增大w——减去负数，等价于加上正数，w自然变大。

一个常见错误是把公式写成w + eta * dJ/dw。只要记住：导数为正，损失随w增大而增大，我们就得让w减小；导数为负，损失随w增大而减小，我们就该让w增大。统一用‘减’号就能覆盖两种情况。

现在你已经看到：从损失出发，我们通过求导获得方向，再用学习率缩放步长，最终完成一次参数更新。下一页，我们将深入讨论：这个步长eta到底多大合适？为什么有时走着走着反而震荡起来了？

## 第5页：E1：教材计算图逐步求导

### A

我们来解这个计算图：e等于(a加b)乘以(b加1)，其中a取2，b取1。

先做前向传播：定义中间变量c等于a加b，得3；d等于b加1，得2；最终e等于c乘d，结果是6。

现在反向求导：在乘法节点e=c×d处，局部导数de/dc等于d，即2；de/dd等于c，即3。

a只连到c，所以de/da = de/dc × dc/da = 2 × 1 = 2。

而b同时连到c和d——它经过两条路径影响e：一条经c，一条经d。

第一路径b→c→e的贡献是de/dc × dc/db = 2 × 1 = 2；第二路径b→d→e的贡献是de/dd × dd/db = 3 × 1 = 3。

总偏导de/db是两路贡献之和，2加3等于5。注意：不能相乘，也不能漏掉任一路——这是链式法则在多路径结构中的核心规则。

这个小例子清晰展示了神经网络中梯度如何沿计算图回传：每个输入对输出的影响，是所有通路贡献的代数和。

### B

我们来解这个计算图：e = (a + b) × (b + 1)，其中 a = 2，b = 1。

先做前向计算：令 c = a + b = 3，d = b + 1 = 2，于是 e = c × d = 6。

从输出 e 反向推局部导数：e 对 c 的偏导是 d，即 2；e 对 d 的偏导是 c，即 3。

a 只通过 c 影响 e，所以 ∂e/∂a = (∂e/∂c) × (∂c/∂a) = 2 × 1 = 2。

b 却不同——它同时进入 c 和 d 两条路径：经 c 的贡献是 2 × 1 = 2，经 d 的贡献是 3 × 1 = 3。

因此总偏导 ∂e/∂b = 2 + 3 = 5。注意：这里必须相加，不能相乘；漏掉任一路径就会出错。

这个小例子完整体现了反向传播的核心规则：同一路径上局部导数相乘，多条路径对同一变量的贡献相加。

### C

我们来完整走一遍教材中的计算图求导过程，它直接体现反向传播如何处理共享变量的多路径影响。

给定表达式 e = (a + b) * (b + 1)，其中 a = 2，b = 1。先做前向计算：令 c = a + b = 3，d = b + 1 = 2，那么 e = c * d = 6。

现在从输出 e 往回求局部导数：e 对 c 的偏导是 de/dc = d = 2；e 对 d 的偏导是 de/dd = c = 3。

输入 a 只通向 c，再由 c 通向 e，路径唯一，所以 de/da = (de/dc) × (dc/da) = 2 × 1 = 2。

而 b 不同：它同时参与生成 c 和 d，因此有两条独立路径影响 e。

第一条路径 b → c → e 的贡献是 (de/dc) × (dc/db) = 2 × 1 = 2；第二条路径 b → d → e 的贡献是 (de/dd) × (dd/db) = 3 × 1 = 3。

最终 ∂e/∂b 是两路贡献之和：2 + 3 = 5。这里的关键易错点是——多路径必须相加，绝不能相乘，也不能遗漏任一路径。
