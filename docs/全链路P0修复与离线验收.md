## 讲稿与配音契约

模型优先返回以下结构；内部持久化仍转成兼容现有流水线的逐句 `口播 | 目标` 和逐页 `###`：

```json
{"pages":[{"sentences":[{"speech_text":"错误率为15.3%。","cursor_prompt":"\"错误率\""}]}]}
```

共享解析器也接纳上一轮真实模型产生的“口播换行后才写 `| 目标`”、多行引号目标、同段多个目标以及完整尾句。重复目标不会增加一次配音。空句、空目标、未闭合引用、疑似截断和页数不符仍拒绝。课程逐页生成器在组装前同样规范化 JSON，防止多个 JSON 对象直接拼成坏讲稿。

`spoken_text.py` 在发送配音前处理年份、整数、小数、百分比、常见希腊字母和运算符；例如 `15.3%` 对应“百分之十五点三”，不会删除小数或把它当脚注。原文保留在字幕、定位及 `text` 字段中；`spoken_text`、`spoken_sha256`、`normalization_version`、`normalization_language`、`normalization_map` 记录转换后的口播与原文起止区间。P6 提取原文片段使用完整 `original_end`，不会截断展开后的数字 token。

全章先规范化预检，再开始第一笔 TTS 请求。未知 LaTeX 命令、未识别控制字符会要求明确口述。中文支持常见运算符的字面读法，不自动推导公式含义。非中文维持文字映射，供应商如果自行改写导致字词不符仍拒绝。

供应商真实字词必须完整覆盖提交口播，并满足时间顺序、音频采样界限及哈希配对。定位按规范化口播的字词边界取时刻，展示内容仍是原文；没有均匀时间轴兜底。SSE 的临时词组被最终分词修订时，重叠字符区间会被替换，防止重复计词。接口字段依据[百炼 CosyVoice HTTP API](https://help.aliyun.com/zh/model-studio/cosyvoice-tts-http-api)。

默认 TTS 块目标改为 180 字符，API 硬上限仍为 400。缓存指纹包含规范化版本和分块策略；重复成功块可以复用。未知受理标记仍禁止自动重提，映射失败也不会偷偷拆块再次收费。映射失败时保存脱敏 `tts_diagnostics/<usage_id>.json`，只含文字哈希、采样数和字词事件，不含音频数据、临时地址或凭据；已返回用量仍计入费用。

`paper_struct` 在模型调用前拦截有质量问题的 PDF；指定 `--text-file` 的课程正文也检查缺字标记，不能绕过这一门禁。对已核对的正文，可按现有 CLI 传入：


该命令的 PDF/已审核正文排版本身不调用模型。此处“已审核”是调用方确认文本的前提，参数不能自动证明转录正确。当前验收夹具只含第一页摘录，不能拿它替代整章。

PDF/审核正文按原句逐段排版并转义 LaTeX 特殊字符，避免模型重写正向微分定义、数字或公式；其他输入的模型版式如果丢失原段落、改变公式或产生未追溯长文本，同样退回原文排版。`source_binding.json` 保存源文件、正文、LaTeX 和段落哈希及编译结果；Web 复用与结构化缓存同时核验绑定，正文/产物被改、源文件丢失、旧绑定或编译失败均不能当作合格缓存继续运行。缓存发布同步保存绑定，提取器版本升至 2，产物缓存版本升至 4，课程讲稿缓存版本升至 4。

这保证来源文字保留，不代替公式转录审核、复杂数学排版或讲稿事实审核。高级公式、布局裁切、配图错配、字幕遮挡及 `no` 光标问题仍属于后续范围。

## Wan 与 P6

合片前检查主 WAV 哈希、采样数量、分段连续覆盖和 PCM 字节一致性。字词侧车必须通过原稿、音频和时间范围的完整校验。

超过一帧的短缺只有同时满足以下条件才延展末帧：缺口不超过 0.5 秒；缺失样本区域的 16-bit PCM 绝对峰值小于 256；没有任何字词与缺口重叠。一帧内的量化差异也不得截掉时间戳仍在发声的字词。缺少可信字词证明时不准以较大补帧掩盖缺失。

上一轮实测样本：输入音频 6.32 秒，Wan 视频 6.125 秒，末字 5.92 秒，缺口 PCM 峰值/RMS 均为 0。新合片 512×512、25 fps、6.32 秒，仅一条完整主音轨，FFmpeg 全片解码通过。供应商原计费时长仍为 **6.13 秒**，不会按本地延展时长追加云费用。P7 远程 ID、恢复、未知受理和取消保守状态保持原语义，相关回归通过。
