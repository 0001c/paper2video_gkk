# 字幕自动换行与样式配置

## 前端使用

- 新建任务：在“光标与字幕 → 字幕样式”设置字幕。草稿保存在本机浏览器，刷新会恢复。
- 已有任务：任务详情显示独立的字幕样式，修改用于下一次审核合片或续跑，不会立即改写已有成片；不会借用新任务草稿。
- 支持开关、字体名称、字号、文字颜色、背景颜色、背景不透明度、左右安全边距、底部距离，以及恢复默认和实时示意预览。
- 字号以1080p高度为基准等比例缩放，例如32px在1418高的视频上为42px。自定义字体必须在运行FFmpeg的服务器上安装；缺失时libass会寻找替代字体，浏览器预览不能保证字体完全一致。
- 字幕自动换行不可关闭。中文无空格长段、英文单词及无空格长词均有显式换行兜底；英文尽量在空格处断行。
- 段落过大可能按当前画幅自动缩小字号以避免纵向裁切；仍无法完整显示时明确报错，不静默截断。长段落依然可能遮住课件，建议精简段落。
- 本次仅调整呈现，保留cursor.json原始起止时间，不生成均匀伪时间轴，也不把长段字幕改成词级/句级滚动字幕。

## 后端与CLI

既有接口接收`subtitle_style`，不新增服务或依赖：

- `POST /api/jobs`：位于`config.subtitle_style`。
- `POST /api/jobs/{id}/rerun`、`POST /api/jobs/{id}/review/run`：位于请求顶层。
- 缺省或部分配置自动补全默认值；任务config快照及SSE回显样式。续跑未提供新值时继承来源任务。
- 请求中的未知字段、非法颜色、ASS字体分隔符、NaN/Infinity、错误类型或越界数值返回422，错误明确标出`subtitle_style.<字段>`。
- CLI：`--subtitle-style`接受同一JSON对象，后端与渲染共用`Paper2Video-main/src/subtitle_style.py`的归一化规则。只改变样式无需重新合成配音。

```json
{
  "enabled": true,
  "font_name": "",
  "font_size": 32,
  "text_color": "#FFFFFF",
  "background_color": "#000000",
  "background_opacity": 0.55,
  "margin_horizontal": 5,
  "margin_bottom": 3
}
```

| 字段 | 范围与含义 |
| --- | --- |
| enabled | 布尔值；关闭时复制无字幕视频到最终输出，不重新编码 |
| font_name | 空字符串跟随讲稿语言；字体名最多80字，无控制符、逗号、反斜杠和花括号 |
| font_size | 16—72整数，1080p基准像素 |
| text_color / background_color | `#RRGGBB`，无Alpha后缀 |
| background_opacity | 0—1；0关闭底色并使用黑色描边 |
| margin_horizontal | 宽度的2%—20%，左右各自留白 |
| margin_bottom | 高度的1%—15%，距画面底部 |

ASS改为自动换行，并按实际宽度和字号预置安全换行；保留文本转义，背景使用ASS BGR与反向Alpha。每次烧录使用独立临时ASS文件，通过cwd与纯英文文件名引用，成功/失败后清理，不在任务之间共享固定字幕文件。
