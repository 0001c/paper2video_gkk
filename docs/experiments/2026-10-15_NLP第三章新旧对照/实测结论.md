# 第三章新旧讲稿实测：衔接有局部改善，时长与准确性仍未达标

本轮没有证明新版已经适合直接生成成课讲稿。新版得到更高的模型辅助评分，但讲得更长，仍有重复、提前给出后页答案和形状推理错误。应保留逐页上下文方向，先解决修订执行和校验覆盖，再扩大实验。

## 实验范围与共同条件

采用用户指定的《自然语言处理第三章(1).pdf》3.4–3.7，PDF第9–16页，内容为计算图、张量、会话及代码示例。固定8页共同课件，目标12分钟，允许10.8–13.2分钟。A为改进前生成器（d9e210c），B为加入实际前文、本页任务、后页问题、加权预算和两次综合修订的生成器（c252590）。每组两次，顺序A1→B1→B2→A2。

两组共用教材摘录、课件、勘误、明确标记的补充数值、qwen3-vl-plus及temperature=0.3；生成并发均为1。没有加入新的B站方法卡，因此本轮测的是上一轮工程改进的合并效果，不能分离各项改动的因果贡献，也不是整章PDF到视频的端到端测试。生成前方案及输入指纹保存在同目录。

## 教学衔接：有正例，也有未解决的问题

- **局部改善**：A1第3页承诺“下一页 x 与 W 的矩阵乘法”，实际下一页是会话，第6页才核对形状。B1相同位置引向Session，与第4页匹配。
- **重复仍在**：B1第1、2页以完全相同的“我们刚写出 h = sigmoid(W·x + b)……”开场；第4页又重讲第2页的完整E1数值例子。
- **没有完全管住后页内容**：B2第1页已经提出如何“分步得到20”，把下一页的最终答案提前说出。A2也提前给20，因此不是新版独有问题。
- **实际前文不等于正确引用前文**：A1第2页把前页h错误回顾成(a+b)*c；B2第2页回顾h时又漏掉前页的sigmoid。

长句逐字重复代理指标为A1=0、A2=0、B1=1、B2=0，只统计规范化后至少14字符的完全相同句子；不能拿它证明没有语义重复。16条逐页证据均核对到指定样本及页码，详见“执行代理逐条复核.json”。这是执行代理的事后审阅，不是独立教师评分或穷尽错误率。

## 计算：固定答案正确，解释仍会错，门禁也会误报

四份均给出了E1最终20、x[1,10]乘W[10,5]得到[1,5]、总计55个参数。E1数值是共同教学补充，不是原书给定；两组均收到这个说明。以下问题仍存在：

| 定位 | 发现 | 核对结论 |
| --- | --- | --- |
| A1/A2及B1多个页 | 又使用W·x，与形状页的xW矛盾 | 未保持整课符号与矩阵顺序一致 |
| B1、B2第6页 | 反向W乘x的“不匹配内维”说成10与5或5与10 | 实际内维为5与1，结论不兼容对，理由错 |
| A2第5页 | 把W、b都称为随机值 | 原代码W随机，b为零初始化 |
| A2第6页 | “广播只作用于末轴” | 广播从末轴对齐并逐轴比较，不能这样概括 |
| A1第2页的门禁 | 报告没有给出z=20 | 正文已有“用d的结果算z：5乘4等于20”，属于口述结果解析误报 |

另一个需澄清的说法是A1“若误用[5,1]就会出错”。本地NumPy反例表明[1,5]+[5,1]可以广播成[5,5]，需要说明这种静默形状扩张。原句的“出错”可能指结果形状错误，不能擅自把它记作确定声称会抛运行异常。

本地实际核对了矩阵形状、广播及55参数，没有安装/执行TensorFlow或教材中的命令。TensorFlow加法使用NumPy广播规则，参考[官方加法说明](https://www.tensorflow.org/api_docs/python/tf/math/add)；乘法尺寸与按依赖执行参考[matmul](https://www.tensorflow.org/api_docs/python/tf/linalg/matmul)、[Session](https://www.tensorflow.org/api_docs/python/tf/compat/v1/Session)。

这些反例说明，现有“显式常数等式+有限例题结果”校验不能证明张量形状或整段技术叙述正确。A1的口述等式也没有被通用等式解析器复算，不能将checked=0记为已核验通过。

qwen3.8-flash进行了四次匿名比较，每轮交换A/B位置，七维各1–5分。引文都可定位到对应版本页，因此四次均按预定规则保留；“引文归属通过”不表示评语中的事实判断正确。

B2问答正常结束但漏Q10–Q12，未补答或重抽。其余三份全部答对只能说明这套题未区分它们，不能证明学生学习效果，也不能比较两组完整问答均值。新版更长、解释更多，评分与实际课时混杂；同家族模型评审及每组两次均限制外推。

## 配音失败与测量边界

原正式audio阶段在A1第二块因云时间戳映射失败中止：正文tf.Variable，聚合时间戳多了一个“点”。提供方已完整返回PCM并记录用量，诊断保留703680采样点，即29.32秒，但该块PCM没有落盘。

为完成时长比较，按“配音测量补充说明.md”单独关闭后续块的词时间戳。原成功块直接复用；失败块只采用诊断帧数，没有重发。A1有7页完整WAV，第1页缺一个块的可试听音频；其余三个样本均保留8页完整WAV及MP3。音频时长结果不等于光标对齐成功，也没有写入生产course_timing。

“结果数据.json”和自动“实测数据汇总.md”的正式audio字段为空，是原方案失败的现场；独立实际时长以“综合复核数据.json”和四个“*_独立音频时长.json”为准。原提交台账仍有一个unknown保护标记，但已由完成诊断与用量记录解释，综合复核中的未解决受理状态为0；没有绕过标记重提。
