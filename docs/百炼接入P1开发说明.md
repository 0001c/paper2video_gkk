# 百炼接入P1开发说明

日期：2026-10-03。阶段：P1配置与凭据底座已实现；P2前端/目录、P3独立角色客户端以及P4至P8云端链路尚未完成。

## 1. 本期已实现

- `web/model_config.py`：严格model_config v2、分角色提供方/参数、旧配置迁移、实际执行角色、能力门禁与数字人派生policy。
- `web/model_connections.py`：连接创建/更新/删除、受信地址校验、环境/瞬时凭据、资源范围ID、按任务冻结连接快照和凭据。
- `web/app.py`：创建、准备恢复、审核后执行、重跑统一规范化；无秘密任务快照；连接重绑；纯配置校验；请求大小/同源保护与不回显输入的字段级422。
- `Paper2Video-main/src/model_runtime.py`及两条pipeline入口：读取`--model-config`快照，拒绝未实现路线，消除v2任务的全局Key回落。
- `pv_env.py`：v2子进程禁止从.env再次注入OPENAI/DEEPSEEK凭据与地址，避免父进程已隔离、子进程又回落。
- `scripts/check_model_config.py`：离线单元检查，不启动服务，不调用HTTP/真实模型，不加载GPU。

当前支持既有单兼容连接的文本/视觉，以及本地Qwen3语音/ASR/对齐/GUI-Owl配置。不同文本/视觉连接将在P3实现；同一个连接下型号可以不同。兼容文本/视觉可以选择API或明确本地服务，不增加权重加载器。

## 2. 当前可用接口

| 接口 | 行为 |
| --- | --- |
| GET /api/options | 新增model_configuration：自动生成的v2 schema及各适配器真实实现状态 |
| GET /api/model-connections | 非秘密连接列表；只标configuration_only，不表示推理已验证 |
| POST /api/model-connections | 创建瞬时连接，201返回ID、scope、端点及key_present；不回显Key、不发网络请求 |
| PATCH /api/model-connections/{id} | 更新标签/Key；现有任务的已冻结凭据不会被自动替换 |
| DELETE /api/model-connections/{id} | 删除未被运行/排队任务引用的瞬时连接；不删除历史产物/云资源 |
| POST /api/model-config/validate | schema/当前执行依赖/适配器/连接/本地资源校验；不推理、不上传 |
| POST /api/jobs/{id}/model-connections/rebind | 停止状态任务显式重绑同scope、同协议端点连接；不会自动续跑 |
| 现有创建/审核后执行/准备恢复/重跑 | 接收v2或迁移旧配置，保存有效快照；冲突的旧控制字段返回422 |

审核/准备恢复/重跑的v2配置字段名为`model_config`；创建仍放`config.model_config`。Pydantic内部字段用model_options，避免与框架保留的model_config类配置冲突。

JSON请求限制：连接16KiB、模型/任务256KiB、原审核/课程请求500KiB。对声明长度与分块实际字节均校验；不因缺Content-Length就无限读入。

## 3. 凭据与环境连接

可在用户本机环境或已忽略的.env配置：

| 变量 | 作用 |
| --- | --- |
| BAILIAN_API_KEY | 百炼环境连接Key；不要写入Git或文档 |
| BAILIAN_COMPATIBLE_BASE_URL | 用户提供的兼容基址；必须为认可的HTTPS阿里云主机 |
| BAILIAN_NATIVE_HTTP_BASE_URL | 可选，待后续按协议接入，不自动猜测 |
| BAILIAN_WEBSOCKET_URL | 可选，待P4确认工作空间WS入口，不回落公网默认 |
| BAILIAN_SCOPE_ID | 非秘密资源归属范围，默认bailian-default；更换账号须换范围 |
| PAPER2VIDEO_MODEL_HOSTS | 逗号分隔、由部署者批准的兼容服务主机名 |
| PAPER2VIDEO_MODEL_NETWORKS | 逗号分隔、由部署者批准的本地服务网络；默认仅loopback |

环境连接ID为`bailian-default`，只在Key与兼容地址均已配置时出现。瞬时连接重启失效；后续前端P2将提示重新绑定，而不是自动借用其他Key。

创建瞬时连接的请求允许显式scope_id用于恢复历史连接范围；这是受信用户的配置声明，不是云端账号已验证。重新绑定须使用历史快照中的scope和相同端点；不允许借重绑偷偷换账号或模型。

任务凭据冻结在进程内。修改连接Key只影响新绑定的任务；旧Key已失效时，应停止任务、明确重绑，再通过原有恢复/重跑入口继续。

现有服务是本机/受信LAN共享工作台：可信设备可管理共享连接与调用其配置，尚未提供按用户隔离的公开多租户认证。不得开放到公网后宣称已完成用户权限控制。

## 4. 快照与CLI

每个新任务保存`job.json`和`model_config.json`。后者只含model_config、来源、非秘密连接快照和派生policy，使用临时文件+replace写入。

子进程命令只增加`--model-config <任务目录/model_config.json>`；凭据通过任务级环境变量传递，不进入argv。当前P1兼容桥在一个任务开始时设置唯一兼容连接；P3再改成真正独立的角色客户端，不在运行中切全局端点。

- 老请求/历史任务迁移为model_config_origin=legacy，保留原本本地语音/定位/数字人路线与环境回落行为。
- v2任务只使用自己的连接快照及凭据；不允许旧api_key/api_base/text_model/vision_model/generate_talking同时控制。
- 原本缺肖像自动关闭的行为只保留在legacy；v2开启数字人必须明确提供本服务内的有效肖像。
- API音色/语音/定位/Wan当前执行会被adapter_not_implemented拦截，而不是偷偷走本地。
- 课程教案预览当前为本地计算，没有为它新增伪API推理；云音色接口和模型目录合并/分页仍留给后续阶段。

## 5. 数字人时长规则的当前状态

开启时派生`max_segment_seconds_exclusive=20`、`target_segment_seconds=18`；关闭时两者为null。**P1只建立策略与门禁，实际音频切分尚未实施。** policy包含implemented=false；实际规则将在P6落地。

因此v2任务执行数字人阶段暂时拒绝，避免宣称已经保证严格小于20秒。legacy路线保留旧执行能力，不把它假装成已完成新分段验收。页/整片时长字段没有修改。
