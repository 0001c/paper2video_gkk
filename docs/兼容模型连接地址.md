# 兼容模型连接地址

DeepSeek 官方连接请选择 **OpenAI 兼容 / 本地服务**，兼容 Base URL 填写 `https://api.deepseek.com`，也接受 `https://api.deepseek.com/v1`，使用官方平台 API Key。[官方接入说明](https://api-docs.deepseek.com/)。

原先服务只允许本机地址或 `PAPER2VIDEO_MODEL_HOSTS` 显式配置的域名，因此添加官方地址会在本地校验阶段报“兼容模型主机未在服务端白名单中”，尚未向 DeepSeek 发出请求。现在内置精确允许 `api.deepseek.com`，仅限 HTTPS 默认端口；不放行任意子域、相似域名、HTTP、携带账号密码或查询凭据的地址。

其他云端服务仍需在服务端设置 `PAPER2VIDEO_MODEL_HOSTS`，使用英文逗号分隔精确主机名，例如 `example-provider.com,second-provider.com`，不包含协议和路径。本机及显式配置的私网连接沿用已有规则。

后端模块需要重新加载才生效。连接可选择“将密钥加密保存到本机（重启后恢复）”，使用 Windows 当前账户 DPAPI 加密；取消保存时仅保留进程内存连接。本次只验证配置和接口，不验证真实账号权限、余额或推理效果。保存方法见 [本地密钥保存](本地密钥保存.md)。
