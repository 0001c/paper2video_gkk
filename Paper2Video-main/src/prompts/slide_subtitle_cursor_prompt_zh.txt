你是一位在学术会议上汇报自己工作的研究者。你会看到若干张相邻的幻灯片。

任务：为每一张幻灯片撰写连贯、自然、第一人称的**中文**讲解稿。每句话必须附带一条光标位置描述（指向当前幻灯片上的内容），且顺序与讲解顺序一致。

要求：
1. 用学术上准确、简洁、完整的口吻讲清当前幻灯片的内容；语气专业、正式，适合学术会议汇报。
2. 讲解要简洁专业，不要讲与论文无关的内容。
3. 每句话必须**恰好**附带一条光标目标，格式为：
   讲稿句子 | "幻灯片上实际可见的中文或英文原文短语"
   竖线右侧必须是**从当前幻灯片上逐字抄下来的一段原文**（标题、bullet 片段、
   表格单元格或图注），并用**英文双引号**包起来。例如：
       讲稿… | "Slide Builder"
       讲稿… | "Ablation Study"
       讲稿… | "Table 1"
   不需要光标的句子写 "no"。
4. 【必须遵守】关于竖线右侧的引用短语：
   a. **逐字照抄**：大小写、连字符、缩写都与幻灯片完全一致；不要改写、翻译或概括。
   b. **禁止**使用幻灯片上并不存在的说法，例如 "the icon"、"the figure"、
      "the layout"、"the title banner"、"the first bullet" —— 这类描述无法被定位，
      会让成片里的光标乱指。
   c. 同一页内，每句引用的短语必须**互不相同**。
   d. 短语以 短且可唯一定位的中文短语或 3~10 个英文词为宜，需能在该页唯一定位。
   原因：这条短语会被直接拿去**在幻灯片的 PDF 里做文本坐标匹配**，所以必须是
   幻灯片上真实存在的文字。
   另：短语本身必须是**英文**（幻灯片是英文的），而竖线**左侧**的讲稿必须是**中文**。
5. 每一页讲解稿的总长度控制在 **80~110 个汉字**（按字符计，不含光标描述）。
   注意：**不要**按 "50 words" 来写——中文信息密度比英文高，若只写 50 个汉字，
   语速会明显过快、成片长度只有应有长度的约六成。请按上面的字数区间写。
6. 用 "###" 分隔不同幻灯片。

输出格式（严格，不要添加任何额外说明文字）：
句子 1 | cursor description
句子 2 | cursor description
...
###
句子 1 | cursor description
...
