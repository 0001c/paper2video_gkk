# 教学规划与口播修订改进

日期：2026-10-15。对应第三章新旧实测结论的四项后续工作。基础代码提交 `bbc72ad`；本说明所在提交另补充了回顾原式的前文证据核对。

本轮落实生产逻辑和离线回归，没有再次生成收费讲稿或云配音。原实验目录、输入指纹、讲稿、评审、配音和未知请求记录均保留为历史证据。

## 1. 修订没有变化时及时停止

每次响应保存后，提取纯口播，按真实配音所用的规范展开公式、数字和代码标识符，再计算指纹。空白、标点和光标目标变化不会被算作新的口播。

- 相邻修订口播相同：`no_oral_change`，立即停止后续自动修订。
- 修订回到更早候选：`repeated_oral_content`，停止循环。
- 未达到质量要求且用完初稿加两次修订：`repair_limit`，停在审核。
- 计算、教学局部检查和预算均通过：`quality_passed`。

超长修订请求附带逐段清单：原单位数、目标单位数、段落开头及保留推导标记。段落按机器讲稿的每行划分；目标合计为本页分钟数乘语速，条件、因果、推导和结果段获得更高保留权重。它是给模型的删改目标，不会在本地截断正文，也不能保证不合理预算可实现。

候选、用量、指纹、逐段目标、`stop_reason` 和 `needs_review` 保存在 `course_script/*.json`。恢复复用已完成结果，不因为未达标继续付费。审核 API 显示停止原因，计算或时长门禁仍失败时不能开始配音。

## 2. 教学清单有知识归属、实际证据和待核对问题

每页正文生成 `P页码.K序号` 知识项；问题使用 `Q页码`，明确负责回答的页和下一页承接问题。本页目标加入具体知识项，不再只有通用任务句。前文最多一句承接，后页内容有明确归属。

生成后页时提供：本页清单、前面实际口播、前文知识项的原文证据、实际提出的跨页承诺、负责页及后页路线。长课的前文清单按完整条目保留最近约一万字符；生成缓存仍绑定完整前文，最终审核检查全课。

审核报告 `lesson_ledger` 和界面中的“本页教学核对清单”区分：

| 记录 | 自动判断的范围 |
| --- | --- |
| 知识原文证据 | 完整原文是否出现；出现仍需核对解释，转述不判漏讲 |
| 实际跨页承诺 | 保存原句；明确“下一页”或数字页码时分配负责页，含糊“后面”留待指定 |
| 到负责页的问题 | 提示核对回答，不把关键词出现等同于兑现 |
| “前面写过”的原式 | 对照实际前文查字面证据，未找到则警示核对符号；转述不自动判错 |
| 重复讲解 | 非回顾页重复开场、重复多句或长句进入修订，允许一次简短必要承接 |
| 提前结果 | 已核验例题在负责页前明确给出结果时进入修订 |

这些检查不等同于语义评审。改写后的重复、隐含问题是否回答、自然语言回顾是否准确，仍需要人工核对。报告不会把它们伪装为“已完成”。

## 3. 张量约束及数值口述

新增 `tensor_checks.py`，从已审核 `kind=shape` 例题的原文和步骤中提取具名方括号形状与明确乘法顺序，按例题保存来源；不执行教材代码或加载 TensorFlow。全课共享一致性表，但只在负责页展开完整例题。

目前覆盖显式二维矩阵乘法、输出形状、末轴对齐的广播，以及有限反例表述。例如第三章的约束是 `x[1,10]`、`W[10,5]`、`b[5]`：

- `x×W` 输出 `[1,5]`；把 `W×x` 当成本例有效计算会被拦截。
- 反向乘法的实际内维是 **5 与 1**；将报错理由写成 10≠5 或 5≠10 会被拦截。
- `[1,5]+[5]` 仍为 `[1,5]`；`[1,5]+[5,1]` 合法扩成 `[5,5]`，不能说必然运行报错。
- 不把广播概括成“只作用于末轴”。

多例题复用同名符号且形状不同，没有指定作用域时显示未覆盖；不强行拼成一套约束。批量高阶乘法、动态维度、转置、复杂反向操作及未支持的口述仍在范围外。`tensor_checks` 区分教材约束复算和口播匹配记录，`uncovered` 明确列出可识别但未匹配的式子。通用算术也会列出未覆盖的符号式，例题结果另行核对。

数值结果可识别 `z=20 的 Tensor` 和 `z：5乘4等于20`。不会把“两路贡献”中的“两”当作最终梯度；同一句中的 `z=20…z=30` 仍报告矛盾结果。原有有限 AST 数值核验和舍入容差保留。

## 4. 先确定代码读法，再校验云时间戳

中文口述规范升级为 2：

| 展示原文 | 配音文字 |
| --- | --- |
| `tf.Variable` | `tf点Variable` |
| `tf.nn.sigmoid` | `tf点nn点sigmoid` |
| `feed_dict` | `feed下划线dict` |
| `w_1` | `w下标一` |

展开字符逐个映射回原文位置，展示讲稿及光标引用保持原格式。审核页面提供“实际口播预览”，需保存后更新。英文路径本轮保持原有读法。

云时间戳仍须完整匹配规范化口播，且时间有限、单调、不越界；缺“点”、多“点”或映射版本不一致都会失败，不放宽校验，不回退本地平均对齐。

规范版本参与云音频缓存和审核版本；旧规范的语速校准不自动沿用。旧云音频可能因规范升级失效，需要用户显式执行配音才会生成新版本。未知受理标记增加页内检查，即使规范版本改变了分块缓存键，也禁止自动重提该页；显式音频修复沿用原有独立恢复目录机制。
