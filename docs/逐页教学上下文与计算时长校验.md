## 生成每页讲稿时提供什么

教材模式和带教案的课程按页顺序生成。每次请求包含：

| 输入 | 用途 |
| --- | --- |
| 本页任务、讲解范围、需要回答的问题 | 说明这一页应讲清什么 |
| 前面实际生成或人工保存的口播摘录、最近一页正文 | 避免把前页标题误当成已经讲过的内容 |
| 后面页面的任务、下一页承接问题 | 留下必要的引子，把后页的完整推导留到对应页面 |
| 本页例题的已核验条件、步骤和结果 | 当前页展开对应例题，避免每页重复整章例题 |

任务先根据已渲染课件的标题、正文及例题 ID 生成，区分问题引入、概念解释、例题推导、回顾检查。它是确定性初始规划，没有额外增加一次模型规划调用。模型仍需结合教材和图片写出具体讲解；当前规则不能保证所有跨页问题都被兑现，也没有自动判断所有语义重复。

较早页面保留首尾句摘录，总窗口最多约 2800 字符，最近页另保留最多 1400 字符；后续路线最多约 2600 字符。缓存指纹绑定全部前页口播，而不只绑定这些摘录。长课仍可能遗漏前页中间的细节，应在审核时检查。

审核界面显示当前页任务和下一页承接问题。局部重写时读取当前保存的前文，其他页保留；如果前页已改、后页仍沿用旧上下文，教学报告会提醒复核后页衔接。不会自动连带付费重写全部后页。

教材生成会比原先多页并发慢一些。普通、没有教学约束的讲解仍支持并发。

## 计算校验如何工作

已提取的教材例题继续使用源页、原文指纹和本地计算结果约束。新增检查能识别 `∂e/∂b=2+3=5` 的最终值，也能识别“e 对 b 的偏导等于五”等有限口述表达；同一结果出现互相矛盾的数字会被拦截。

新增的显式数值例子也参与检查，目前覆盖：

- 常数四则等式及有限整数幂。
- 可解析单变量函数的导数、给定初值与学习率的负梯度更新。
- 给定更新前后参数时，“损失从 X 降至 Y”的数值复算。

例如 `J=(w-3)^2`，`w=5`、学习率 `0.1`，本地得到梯度 `4`、新参数 `4.6`、新损失 `2.56`，可检出上次 C2 讲稿中的 `1.96`。常数计算允许六位有效数字的舍入，避免将 `1/3=0.333333` 误判。

表达式通过受限 AST 计算，不使用 `eval`。计算器仅允许受限节点、四则运算、绝对值不超过 8 的常整数幂、单参数 sin/cos，并限制表达式大小和数值范围；不允许导入模块、属性访问或任意调用。

这不是通用数学证明器。中文叙述、复杂符号、多变量更新、几何结论、收敛保证等超出当前解析范围时，不能把“未发现错误”理解成已经证明正确。报告保留实际核验项目和解析范围；部分可识别但不完整的补充函数会给人工复核提示。上次 A1 的“非凸函数深谷”语义结论不在本轮自动覆盖范围。

## 时长如何控制

自定义课程时长采用三层约束：

1. 保留已审核的小节总时长，再按页面任务分配。引入权重 0.6、概念 1.0、例题 1.8、回顾 0.8，例题页因此获得更多时间。
2. 文字预算统计数学口述展开后的汉字与英文/数字词，去掉光标标记和格式。单页和全课估算均检查 ±10%，不靠截断句子凑时长。
3. 配音完成后读取 WAV 的实际帧数与采样率，再检查整课实际时长 ±10%。直接从合片阶段续跑也检查，不能绕过。

每页生成初稿后，把计算和时长问题合并反馈，最多再修正两次。保留全部有效候选和用量，优先选计算问题少的，再选更接近预算的。仍不达标时进入审核，不继续无限生成，也不开始后续收费配音。

真实音频必须与当前口播指纹、WAV 文件指纹匹配。清单里写着“60 秒”但 WAV 实为 80 秒时，按 80 秒计算；缺页、被修改或损坏的音频不能通过验收。单页实际时长偏差也记入报告，真实音频硬门禁针对全课总时长。

若整课有效音频可测，系统还记录当前任务音色的平均实测语速，用于下一次讲稿修订。例如设置 220 字词/分钟，但 220 单位实际读了 80 秒，后续按约 165 单位/分钟估算。此校准只借用于当前任务目录、相同音色及参数身份、相同教案和目标，不修改原教案。音频清单的音色或参数身份改变、身份混杂时不复用；新音色需先完成配音测量，不能预知其真实语速。超出 80～400 单位/分钟的测量不自动采用。

自动时长模式输出估算和测量报告，没有用户指定目标时不强制套用固定分钟数。

## 缓存、恢复和使用

有效候选在发出下一次修正请求前立即保存。中断后从已有候选继续剩余修正额度；完整缓存不会因质量未通过而无限重新付费。缓存最终文本字段损坏时，优先从留存候选恢复。整套讲稿缓存版本同步升级，避免外层缓存绕过新的生成逻辑。

已有任务的讲稿不会因更新代码被自动改写。加载新后端代码后，可新建教材任务，或在原任务审核面板显式选择页面/整套重写。改前页后留意后页衔接提示；实测超时可依据各页报告缩短冗余。同一口述规范版本、音色和文本的有效音频继续复用。规范升级可能使旧云音频缓存失效；升级不能绕过未知受理状态自动重提，详见新增说明。

主要输出位于任务结果目录：

| 文件 | 内容 |
| --- | --- |
| `teaching_plan.json` | 每页任务、范围、问题、例题 ID 和计划时长 |
| `course_script/*.json` | 上下文指纹、有效候选、修正历史与用量 |
| `teaching_report.json` | 例题覆盖、计算问题、文字预算和上下文变动提示 |
| `course_timing.json` | 计划、估算、各页真实时长及全课验收结果 |
| `timing_calibration.json` | 当前音色的实测语速与适用身份 |
