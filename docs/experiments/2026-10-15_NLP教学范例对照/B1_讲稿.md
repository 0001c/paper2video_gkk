# B1 · 8分钟微课讲稿

## 1. 从损失到参数更新

我们面对的核心问题很直接：神经网络的参数w一开始是随机的，预测结果和真实值差距很大，损失J(w)很高；参数该怎么改，才能让损失一步步变小？

答案是沿着损失下降最快的方向走一小步——这个方向就是负梯度方向。数学上，我们用更新公式 w_new = w - eta * dJ/dw 实现它。

这里eta必须大于0，它叫学习率，控制我们每次迈多大步；dJ/dw不是w对J的导数，而是损失J对参数w的导数，也就是当前点的斜率。

为什么是减号？因为导数dJ/dw为正时，说明w增大让损失变大，那我们就该减小w；导数为负时，w增大让损失变小，我们反而要增大w——统一写成减去正的学习率乘以导数，就自动实现了‘往低处走’。

整个流程是四步闭环：先初始化参数，再前向预测得到输出，接着计算损失J(w)，最后用梯度信息更新参数。

注意，计算导数和执行更新是两个独立步骤，不能混为一谈；导数告诉我们‘该往哪走’，更新公式才真正执行‘迈步’动作。

本页目标是建立‘损失→导数→更新’的因果链：损失告诉我们有多错，导数告诉我们错的方向和陡峭程度，更新则把这一信息转化为参数的实际调整。

## 2. 学习率与优化边界

上一节我们确立了参数更新的核心公式：w_new = w - η · ∂J/∂w。

其中负梯度 -∂J/∂w 给出当前点损失下降最快的局部方向，就像站在山坡上，它指明哪边坡最陡、往下滚最快。

但方向只是第一步——真正决定你能否高效抵达低谷的，是每一步迈多远，这由学习率 η 控制。

η 是一个正数，它直接缩放梯度的大小：η 小，步子小；η 大，步子大。

如果 η 过小，比如 10⁻⁵，每次更新几乎原地踏步，训练进展极慢，可能需要上万轮迭代才能靠近最小值。

而如果 η 过大，比如 1.0，一步就跨过最低点，甚至冲到对面山坡，导致损失值上下剧烈震荡；更糟的是，可能彻底发散，数值爆炸、训练失败。

这里必须强调：神经网络的损失函数通常是高度非凸的，布满多个局部极小值和鞍点。

因此，梯度下降只能保证你沿着当前斜坡向下走，却不能保证最终停在全局最深的那个坑里——它找到的是局部最优解，而非全局最优。

所以选择学习率，本质是在‘稳健收敛’与‘快速下降’之间做权衡：太保守浪费时间，太激进可能前功尽弃。

接下来我们将看到，这个关键的梯度 ∂J/∂w 并非凭空而来——它需要通过反向传播从输出误差回传计算，而参数更新只是最后一步动作。

## 3. 反向传播负责计算梯度

上一节我们明确了：参数更新的方向由负梯度决定，步长由学习率控制；但梯度本身从哪里来？这正是本页要解决的核心问题。

训练神经网络时，系统必须完成四个清晰分离的环节：先做前向传播——输入信号流经网络得到预测值；再计算损失——比较预测与真实标签得出误差大小；接着反向传播——从输出误差出发，逐层回传局部导数，算出每个参数对损失的影响程度；最后优化器才用这些梯度去更新参数。

注意，‘求梯度’和‘用梯度更新参数’是两个独立步骤。就像修路工人先测量坡度，再决定推土机该往哪推、推多远——测量不等于施工。

反向传播的本质，是从输出端开始，沿着计算图逆向传递‘局部导数’。它不重新计算整个函数，而是复用前向过程中已存的中间结果，高效地累积每条路径对最终损失的贡献。

优化器只负责执行更新公式 w ← w − η·∂J/∂w，它不关心梯度怎么来的；而反向传播专精于回答‘∂J/∂w 等于多少’。这种职责划分，让算法设计更模块化、也更易调试。

## 4. 链式法则与中间结果复用

反向传播的核心任务，是高效算出每个参数对最终损失的偏导——但一个参数往往不只走一条路影响输出。比如变量b，它可能同时参与加法和乘法，最后共同决定结果e。

当影响路径唯一时，链式法则要求局部导数相乘：若e依赖c，c依赖a，则∂e/∂a = ∂e/∂c × ∂c/∂a。

而当存在多条独立路径，比如b既通过c=a+b又通过d=b+1影响e，总梯度就是各路径贡献之和：∂e/∂b = (∂e/∂c)(∂c/∂b) + (∂e/∂d)(∂d/∂b)。

关键优化在于：中间节点的导数一旦算出，就能被多个上游参数复用。例如∂e/∂c和∂e/∂d只需计算一次，就可同时用于求∂e/∂a与∂e/∂b，避免重复展开整个表达式。

这种反向模式特别适合神经网络训练场景：我们有成千上万个权重作为输入，却只关心一个标量损失值作为输出。

下一页，我们就用教材例题e=(a+b)(b+1)，代入a=2、b=1，一步步验证：为什么∂e/∂b等于5——它正是两条路径贡献2与3的和，漏掉任一路径都会导致梯度错误。

## 5. E1：教材计算图逐步求导

我们来解这个计算图：e = (a + b) × (b + 1)，其中 a = 2，b = 1。

先做前向计算：令 c = a + b = 3，d = b + 1 = 2，于是 e = c × d = 6。

从输出 e 反向推局部导数：e 对 c 的偏导是 d，即 2；e 对 d 的偏导是 c，即 3。

a 只通过 c 影响 e，所以 ∂e/∂a = (∂e/∂c) × (∂c/∂a) = 2 × 1 = 2。

b 却不同——它同时进入 c 和 d 两条路径：经 c 的贡献是 2 × 1 = 2，经 d 的贡献是 3 × 1 = 3。

因此总偏导 ∂e/∂b = 2 + 3 = 5。注意：这里必须相加，不能相乘；漏掉任一路径就会出错。

这个小例子完整体现了反向传播的核心规则：同一路径上局部导数相乘，多条路径对同一变量的贡献相加。

## 6. 串联训练流程与检查理解

现在我们把整套训练流程串起来：前向计算得到预测值，用真实标签算出损失，再反向求梯度，最后用梯度更新参数。

注意，反向传播只是高效计算梯度的手段，它本身不等于梯度下降；更新动作发生在求出梯度之后，由学习率控制步长。

在计算图中，同一路径上的局部导数要相乘，比如从b到c再到e，贡献是∂e/∂c × ∂c/∂b；而b同时通往c和d两条独立路径，最终对e的影响必须相加，不能相乘也不能遗漏。

学习率η是一个正标量，太小会让更新缓慢，太大则可能跳过极小点甚至发散；更关键的是，神经网络的损失函数通常是非凸的，梯度下降只能保证局部下降，无法保证找到全局最优解。

我们回头检验一个核心理解点：为什么b的偏导要包含两路？因为b既参与构造c=a+b，又参与构造d=b+1，而e=c×d，所以b通过c影响e的贡献是2×1=2，通过d影响e的贡献是3×1=3，总和为5——漏掉任一路都会导致梯度错误。
