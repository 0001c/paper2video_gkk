# C2 · 8分钟微课讲稿

## 1. 从损失到参数更新

我们面对一个具体问题：网络当前参数w给出预测，预测与真实值的差距形成损失J(w)，但w不知道该怎么改——它只能感知当前位置的局部坡度。

梯度下降的策略是：沿着损失下降最快的方向走一小步。这个方向就是负梯度方向，数学表达为w_new = w - eta * dJ/dw。

注意这里的导数dJ/dw是损失J对参数w的导数，不是w对J的导数；它衡量的是w变化时J如何响应。

当dJ/dw > 0，说明w增大时损失上升，我们应减小w；当dJ/dw < 0，w增大时损失下降，我们应增大w——负号统一了这两种情形，确保每一步都降低损失。

eta是一个正数，叫学习率，它控制步长大小；但本页先聚焦方向逻辑：更新的本质，是用局部斜率指导参数移动。

整个流程是闭环迭代：初始化参数 → 前向预测 → 计算损失 → 求导得梯度 → 更新参数 → 再前向……求导由反向传播完成，更新由梯度下降规则执行，二者紧密配合但职责分明。

举个教学小例：若J = (w - 3)^2，当前w = 5，则dJ/dw = 2(w - 3) = 4；取eta = 0.1, w_new = 5 - 0.1 × 4 = 4.6，损失从4降至1.96——方向正确才有效。

接下来我们会看到，当参数通过多条路径影响损失时，比如b同时出现在(a+b)和(b+1)中，它的总偏导是各路径贡献之和，这正是反向传播要结构化解决的问题。

## 2. 学习率与优化边界

上一节我们得到参数更新公式：w_new = w - η · dJ/dw。负梯度方向确保我们朝损失下降的方向走——因为dJ/dw是损失J对参数w的变化率，若它为正，说明w增大时J变大，我们就该减小w；若为负，就该增大w。

但方向确定后，关键问题来了：这一步该迈多大？这就是学习率η的作用——它控制每次更新的步长。

如果η过小，比如10⁻⁴, 参数移动极其缓慢，可能上千轮迭代仍远离低点；而η过大，比如1.0，参数可能一步跨过谷底，冲到对面高坡，损失反而上升；下一轮又反向跳回，形成震荡；更严重时直接发散，损失爆炸增长。

这里必须强调：负梯度只保证局部下降，不保证全局最优。神经网络的损失函数通常是‘非凸’的，就像多山谷地形图，算法可能停在某个浅谷里，而非最深的那个。

举个教学例子：你蒙眼站在山坡上，只能感知脚下局部坡度——你朝最陡下降方向迈一步，但前方是否有更深的谷？你无从得知。梯度下降正是这样一种‘局部聪明、全局不确定’的策略。

接下来我们要解决的核心问题是：这个梯度dJ/dw到底怎么算出来的？它不是凭空出现的，而是靠反向传播从输出回传局部导数得到的——求梯度与用梯度更新，是两个明确分离的环节。

## 3. 反向传播负责计算梯度

上一节我们确定了：参数更新的方向由负梯度决定，步长由学习率控制；但关键问题还没解决——这个梯度，到底怎么算出来？

现在进入训练流程的核心环节：反向传播。它不负责修改参数，只负责计算梯度。

整个训练是一条清晰的流水线：前向传播走一遍，输入变成预测，再和真实值比较得出损失；接着反向传播从损失出发，一层层往回推，计算每个参数对损失的局部影响；最后优化器才用这些梯度去更新参数。

注意：求梯度与参数更新是两个独立环节。就像测绘队先精确测量坡度，施工队再据此铲土——测量结果不会自动变成动作，必须明确传递给执行者。

为什么需要专门的反向传播？因为神经网络的损失函数是层层嵌套的复合函数，直接对原始参数求导会导致表达式爆炸式膨胀。反向传播用链式法则，把大问题拆成小段局部导数，沿路径回传组合。

举个教学例子：设损失 e = (a + b) × (b + 1)，其中 a 和 b 是可调参数。e 对 a 的影响仅经由 c = a + b 一条路径；但 e 对 b 的影响有两条路径：一条经 c，一条经 d = b + 1。漏掉任一路，梯度就错了。

这正是下一页要展开的：同一路径内局部导数相乘，多条路径汇向同一变量时贡献相加。今天先记住——反向传播的使命很纯粹：精准算出每个参数的 ∂J/∂w，为优化器提供可靠依据。

## 4. 链式法则与中间结果复用

现在我们面对一个核心问题：当一个变量像 b 一样，通过多个中间步骤影响最终输出 e，它的总影响该怎么算？

链式法则给出明确规则：沿着一条路径走，每一步的局部导数必须相乘。

但如果一个变量通向输出有多条独立路径——比如 b 同时进入 c 和 d——那么各路径对输出的贡献必须相加，不能相乘，也不能遗漏。

关键技巧在于复用中间结果：一旦算出 ∂e/∂c 和 ∂e/∂d，它们就能被所有依赖 c 或 d 的输入共享，避免重复展开整个表达式。

这种从标量输出反推各输入影响的方式，天然适配神经网络的结构：成千上万个权重作为输入，最终汇聚为一个标量损失值。

下一页，我们就用教材这个具体计算图：e = (a + b)(b + 1)，代入 a=2, b=1，严格按路径相乘、分支相加、中间复用三步，验证 ∂e/∂b = 5 是否来自两条路径的正确叠加。

## 5. E1：教材计算图逐步求导

我们来看一个精巧的小计算图，它直接揭示了反向传播中一个关键规则：当一个变量通过多条路径影响最终输出时，它的偏导数必须把所有路径的贡献加起来。

目标函数是 e = (a + b) * (b + 1)，给定 a = 2，b = 1。先做前向计算：c = a + b = 3，d = b + 1 = 2，e = c * d = 6。

现在反向推导：从输出 e 出发，先算局部导数——e 对 c 的偏导是 d，即 2；e 对 d 的偏导是 c，即 3。

接着回溯输入：a 只连到 c，所以 ∂e/∂a = (∂e/∂c) × (∂c/∂a) = 2 × 1 = 2。

而 b 同时连到 c 和 d，形成两条独立路径：第一条经 c，贡献为 (∂e/∂c) × (∂c/∂b) = 2 × 1 = 2；第二条经 d，贡献为 (∂e/∂d) × (∂d/∂b) = 3 × 1 = 3。

因此总偏导 ∂e/∂b = 2 + 3 = 5。注意：这里不是相乘，也不是只取一路——漏掉任一路径都会导致梯度错误，后续参数更新就会走偏。

这个例子虽小，却完整复现了神经网络中权重梯度的生成逻辑：每条通路的局部影响相乘，所有通路对同一变量的贡献再相加。

## 6. 串联训练流程与检查理解

现在我们把神经网络训练的完整闭环串起来：先做前向计算得到预测值，再用它和真实标签算出损失，接着反向传播求出各参数对损失的梯度，最后用梯度更新参数。

要特别注意：反向传播只是高效计算梯度的算法，它本身不执行更新；更新是独立步骤，由学习率控制步长大小。

在计算图中，影响沿路径传递有明确规则：同一路径上的局部导数必须相乘，而像变量b这样分叉出多条路径影响最终输出e的，各路径贡献必须相加——这正是链式法则的结构本质。

学习率η是一个正标量，它决定每次更新的幅度：太小则收敛缓慢，太大则可能震荡甚至发散；更关键的是，神经网络的损失函数通常是非凸的，梯度下降只能保证找到局部极小点，不能保证全局最优。

我们立刻回顾一个核心问题：为什么b的偏导要包含两路？因为b既参与c = a + b，又参与d = b + 1，而e = c × d；所以b通过c影响e的贡献是∂e/∂c × ∂c/∂b = 2 × 1 = 2，通过d影响e的贡献是∂e/∂d × ∂d/∂b = 3 × 1 = 3，总和为5——漏掉任一路都会导致梯度错误。
