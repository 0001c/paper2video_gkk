# 百炼全链路接入实施方案

方案日期：2026-10-03（Asia/Shanghai）。状态：规划已定稿；P1配置底座已实施，P2至P8待开发。当前代码范围见`百炼接入P1开发说明.md`。

配套文档：`百炼模型配置前端设计.md`、`百炼模型接入接口契约.md`。目录依据为2026-10-02工作空间快照及`百炼API模型目录与链路适配.md`，不是推理权限或效果验收。

## 1. 目标与范围

目标：在前端选择“百炼全 API”，让实际执行的模型推理环节全部使用百炼；同时保留现有本地模型入口，支持逐环节切换与显式混合配置。

- 全 API 指模型推理不依赖本地GPU/权重，不是把LaTeX、PDF处理、FFmpeg、素材解析、审核、队列和缓存全部搬到云端。
- 首版继续使用当前React/TDesign、FastAPI、两条pipeline入口和现有任务队列；不引入新前端框架、通用插件注册中心、Redis或额外微服务。
- 页面、讲稿审核、课程计划、章节、逐页结果、重跑和SSE仍沿用现有工作流与产物契约。
- 全 API 不允许静默回退本地。云端失败显示具体环节及可操作原因，用户明确修改配置后才能重跑。
- 规划轮只交付方案、设计与接口契约；P1开发只做离线配置单元检查，不进行冒烟测试、推理、媒体上传、音色创建或服务重启。

## 2. 已敲定的产品规则

### 2.1 数字人与20秒规则

唯一开关为`model_config.avatar.enabled`，旧`generate_talking`仅由它派生。

| 用户选择 | 分段策略 | 页面/成片时长 |
| --- | --- | --- |
| 开启数字人，百炼Wan | 每段实际音频严格小于20秒，默认目标18秒，超长自动切段 | 不受此20秒规则限制 |
| 开启数字人，本地MuseTalk | 同样执行用户要求的数字人分段规则，便于切换 | 不受此20秒规则限制 |
| 关闭数字人 | 不执行数字人20秒切段/拒绝规则；不要求肖像或数字人凭据 | 保持原有课程时长设置 |

本地路径统一分段是本项目产品决定，不是宣称MuseTalk本身有Wan的限制。没有数字人仍须遵守各TTS接口字符数、文件大小等自身约束，不等于所有资源无限制。

“单段”指送入数字人模型的一段音频，不是单页讲稿、一个句子或整片。长页自动生成多个片段再拼接，不能要求用户将每页写到20秒以内，不能删字、截断或为通过校验擅自加速。

后端校验使用解码后的采样数：`sample_count < 20 * sample_rate`。正好20秒不通过；不要用四舍五入的UI显示值、字数估算或`<=20`。前端不提供能突破此上限的输入框。

### 2.2 预设与切换

| 预设 | 含义 |
| --- | --- |
| 百炼全 API | 所需模型均为百炼，时间轴来自API合成时间戳；新任务的推荐预设 |
| 保留现有本地推理 | 本地TTS/ASR/对齐/GUI-Owl/MuseTalk；文本/视觉沿用已配置兼容服务，不谎称已内置本地加载器 |
| 自定义组合 | 每环节单独指定本地/API及连接；摘要明确显示“混合模式” |

历史草稿/任务不得自动改成新默认。应用预设不重置材料、课程、语言、提示词、肖像；不兼容音色必须提示重新选择。保留当前数字人开关默认行为，但启用且缺少肖像改为字段错误，不再静默跳过。

| 环节 | 百炼首选候选 | 保留入口 | 接入协议/关键要求 |

## 3. 总体结构与最小改造

```text
前端预设 / 分环节设置 / 音色与数字人开关
  -> model_config v2 + connection_id（不传长期持久化密钥）
  -> FastAPI统一规范化与纯配置校验
  -> 每任务有效配置快照 + 内存/环境变量凭据
  -> 原有队列 -> full/light pipeline
       文本/视觉客户端（显式环节参数）
       语音 -> 页主音频 + 时间戳 -> 光标
       avatar.enabled ? 严格分段 -> 本地MuseTalk/云端Wan : 跳过
  -> 原有逐页视频、整片、审核与SSE
```

新增模块限于：`web/model_config.py`负责schema/校验/预设，`web/model_connections.py`负责受信连接与瞬时凭据；`Paper2Video-main/src/model_runtime.py`负责pipeline读取有效配置；`src/bailian_speech.py`、`src/bailian_avatar.py`封装真实接口；`src/avatar_segments.py`负责条件分段。目录读取可放`web/model_catalog.py`，避免继续扩大`web/app.py`。前三个已在P1创建，其余仍是计划路径。

原文件保留职责，先在`wei_utils.get_agent_config`和`scripts/paper_struct.py`显式传入模型/端点/凭据，再在`speech_gen.py`、`cursor_gen.py`、`talking_gen.py`增加小型分派。禁止运行中修改一份全局OpenAI地址来支持不同环节。

CosyVoice SDK若只提供进程级WebSocket配置，限定在当前任务子进程初始化一次；本地兼容客户端仍显式传参。将来增加并行工作进程前重新审查SDK全局状态，不能多连接并发覆写。

## 4. 配音、音色与时间轴

### 4.1 先打通可闭环路径

首版闭环选择支持字级时间戳的系统音色或复刻音色。后端设置流式callback及`word_timestamp_enabled`，一次生成保存音频、原文、时间戳和合成参数。浏览器无需播放流式音频，后端可完成落盘后继续。

- API模式必须在加载本地ASR/TTS/ForcedAligner前分派；已有参考文本时不额外识别。
- `cursor_gen.py`现有直接`align_with_qwen3`调用必须改成时间轴来源分派，否则即使API配音仍会加载本地模型。
- 音频和时间戳先写临时文件，校验通过后以manifest最后提交的方式标记这一对产物有效；仅有wav不算完整缓存。
- SDK字词时间、分句时间的单位/基准先归一化到秒与页起点；句子重复事件去重，处理分块偏移。
- 保留现有`segments[].words[]`的word/start/end消费契约，补充讲稿字符范围映射，不用字符均分冒充真实时轴。
- 现有本地分块拼接含0.35秒间隔，必须计入页时间轴；数字人再分段不得重复插入间隔。

声音设计与时间戳组合暂未得到足够官方保证。可先提供设计资源管理/试听，但只有时间戳兼容性确认后才允许它用于“全 API + 光标”。否则阻止该组合并建议选择已支持的系统/复刻音色，不能偷偷转本地对齐。用户显式选择本地对齐时摘要变成混合模式。

全API无需MiMo凭据。保留MiMo旧入口但明确标成非百炼；本项目没有现成的纯本地声音设计，禁止画一个不可执行的“本地设计”按钮。

### 4.2 数字人条件分段算法

1. 合成并保存完整页主音频与时间轴，供字幕/光标/最终混音统一使用。
2. 数字人关闭时直接退出此算法；超过20秒的页音频照常使用。
3. 数字人开启时优先在18秒目标附近、硬边界前选择句末/停顿/词边界，得到不重叠、无遗漏的采样区间。
4. 无自然停顿时使用硬边界前的安全采样切点；不得裁掉音频。不能保证安全/合法片段则显式报错，而不是上传超长段。
5. 很短尾段仅在合并后仍严格小于20秒且符合模型其他输入要求时合并；是否存在最短长度等以实现时模型规范为准。
6. 每段落盘后复核实际采样时长和文件大小，记录起止采样、页内起止秒、文本范围及hash。
7. 每段独立驱动数字人；输出按同一时间线拼接，用页主音频作为唯一最终音轨，避免双声和累计漂移。
8. 已缓存超长页只重建派生片段，不因启用数字人重新付费合成整页。20秒上限不进入页面/整片总时长字段。

内容完整、段间嘴型/动作自然度、输出帧率与音轨同步必须在后续获授权的真实样片中验收；“拼接完成”不等于效果已验证。

## 5. 云端媒体与异步任务

百炼兼容基址、原生HTTP、WebSocket是同一工作空间下不同协议入口；详见接口契约。TTS和数字人不能全部送到`chat/completions`。

- 本地素材URL/Windows路径不能直接给百炼。开发使用官方临时上传流程；生产应配置私有OSS对象及短期签名URL，不公开整个结果目录。
- 官方临时资源有效期48小时且按模型/主账号绑定，图片检测与生成不能假设共享同一模型绑定URL；需分开申请或使用适用的签名HTTP地址。
- 临时`oss://`资源按官方说明带`X-DashScope-OssResourceResolve: enable`；上传地址是否支持当前工作空间入口必须明确核对，不把HTTP基址替换规则强套所有上传接口。不能假定`Files.upload`有`model`参数。
- Wan音频还须遵守wav/mp3、文件小于15M等输入要求。图片检测通过才能提交生成；同图同模型同账号的已有效检测记录可以复用。
- 上传只在用户明确创建云音色/开始云任务后发生，检查配置不上传。临时资源仅用于本地开发；没有生产存储配置时不宣称可生产部署。
- 首版Wan远程生成串行提交（并发1），保留现有本地队列；不依赖未经核实的高并发额度。
- 提交成功即原子保存task_id/request_id/片段指纹，再轮询。已知task_id只续查，不重新提交。
- 提交超时且不知是否受理时记录`submission_unknown`，先确认远程任务再决定重试，禁止默认重新计费提交。
- Wan结果URL及任务记录有时效，收到成功立即下载归档。输入URL快过期时重新上传，但不因此重新提交已知任务。
- 取消先停止新上传/提交，再按当前模型实际支持情况请求远程取消；未确认取消成功时显示“云端任务可能继续处理/计费”。保留远程ID与结果对账入口。
- 开发临时文件按有效期自然过期；自有OSS仅清理当前任务拥有的对象，受已提交任务引用的输入不能提前删掉。

## 6. 快照、缓存与迁移

当前风险：单个全局端点只覆盖文本/视觉；前端可能记住密钥；目录接口裁到500条；数字人缺肖像会自动跳过；重跑共享输出目录；仅按字数切音频无法保证20秒。

### 6.1 必须保存的快照

`job.json`保存有效`model_config`、非秘密端点/连接范围、音色资源范围、时间轴来源、分段policy版本、目录采集日期及每阶段执行记录。禁止保存API Key、Authorization、上传签名或完整临时带签名URL。旧任务阅读继续兼容。

进程命令只带无秘密的`--model-config`路径；凭据由任务级环境别名或stdin传入，不进命令行、日志、产物与浏览器持久化。环境配置连接可重启恢复；浏览器临时连接重启后必须重绑。

### 6.2 缓存失效边界

| 改动 | 应失效 | 应保留 |
| --- | --- | --- |
| 文本模型/提示词/结构材料 | 对应结构/课件及其下游 | 无关材料缓存 |
| 视觉模型/讲稿 | 对应讲稿及下游音频/光标/数字人 | 已确定课件 |
| TTS/音色/语速/朗读文本 | 音频、时间轴及下游 | 课件与已审核讲稿 |
| 定位模型或坐标策略 | 光标及合成视频 | 音频、课件、讲稿、可复用数字人 |
| 数字人开关/模型/肖像/分段策略 | 分段数字人及合成视频 | 页主音频与时间轴、课件、讲稿 |
| Key轮换，同账号同连接范围 | 重新校验凭据，不自动废弃内容缓存 | 合法已有产物；云资源需核对归属 |

`scripts/artifact_cache.py`现有结构/课件指纹改为按实际依赖的阶段字段计算。音频/定位/数字人manifest各自带版本、模型、非秘密连接范围、参数及内容hash；云音色ID不能跨账号缓存。旧音频无时间戳不能伪装成新的API音频缓存。

重跑保留现有串行队列，增加共享输出写入所有权检查；不能删除其他任务/兄弟重跑仍引用的产物。先构建新的派生产物，再替换当前任务指针；不清空整棵结果目录。

| Key失效、目录失败、模型下线 | 分类错误；历史选择不静默替换，新默认避开下线型号 |
| Wan超时、重启、重复点击、取消 | 不盲目重复计费；凭据重绑后可续查；保留远程ID |
| 旧任务/旧草稿/旧缓存 | 能读取，保留旧路线；无法证明完整的缓存明确标无效 |
| 课程长片/中英讲稿/不同帧率片段 | 总时长规则不误改；字幕/光标/数字人基于同页时间线 |

允许开展时先做离线schema/分段/缓存/错误契约验证，再由用户明确授权最小真实样片；没有通过真实调用前保持“目录可见、调用未验证”状态。

## 9. 实施前需明确的边界

- 账号额度、推理权限与生成效果未验证；不承诺所有候选在该Key下均可用。
- 系统音色必须从支持时间戳的列表选择具体ID；声音设计+字级时间戳若不可确认，则不进入首版全API默认。
- 任意上传完整配音的严格对齐不在本次闭环范围；不能把ASR识别结果当用户原稿的精确强制对齐。
- 临时存储仅供开发；生产存储需用户另行提供OSS配置/权限，不擅自新建云资源。
- 官方异步管理文档有取消接口，但Wan实际可取消阶段/账号权限需要在实现与授权验证时确认，不能把本地取消视为云端取消成功。
- 保留MuseTalk现有解释器路径及权重，不因历史目录名含LongCat而删除依赖环境。
