# 可选质量评估与成片版本备份

任务配置页面新增独立的「评估配置」卡片。勾选项目并设置各自 0–100% 的通过线；未勾选项目不调用评价模型。任务详情也可修改配置，用于下一次评价或修复，历史分数保留。

## 评价项目

| 项目 | 时机 | 评价依据 | 新任务默认 |
| --- | --- | --- | --- |
| 讲稿知识 | 配音前 | 从审核后的原文出题，根据讲稿答题，检查知识覆盖 | 开启，80% |
| 成片知识 | 合片后 | 同一原文题库，根据实际音轨识别及抽样画面答题，作为知识传递对照 | 关闭，80% |
| PPT 展现 | 合片后 | 每页实际成片画面，检查文字/公式/图表可读性、布局、图示教学帮助 | 开启，80% |
| 成片呈现 | 合片后 | 每页前段/中段/后段实际画面、页时间轴、实际音轨与讲稿，检查停留、强调/光标及遮挡 | 开启，80% |
| 配音内容一致性 | 合片后 | 从最终视频独立提取音轨，与审核后的逐页口播比较覆盖、准确性、顺序 | 开启，90% |

新默认用于新草稿；已有草稿和任务没有 `evaluation.checks` 时继续使用原来的讲稿/成片问答，不自动增加收费项目。未开启评价的旧任务保持原有人工审核流程。评价总开关开启时至少勾选一项。

PPT、成片呈现和配音分别取最低页分；每页又取规定维度中的最低分，同时显示平均页分供参考，避免其他页的高分掩盖弱项。所有勾选的成片项目均达到各自门槛，成片才自动通过。只选讲稿评价时，完整成片生成后直接完成。

## 证据与边界

- 逐页评价要求连续的 1–40 页课件图片和有效时间轴。优先读取合片时间轴，旧产物可根据页音频时长定位；页范围与实际成片总时长不符时暂停，不能用不匹配的页号评分。
- PPT 每页抽取中段一帧；成片呈现每页抽取 8%、50%、92% 三帧。视觉扣分必须引用实际抽帧时间及具体可见证据。抽帧能发现可读性和遮挡等问题，不能证明每一帧的同步和运动效果。
- 音轨识别使用本地 Qwen3-ASR；单段最长 60 秒，材料始终来自最终视频。配音扣分引文必须匹配讲稿或实际识别文本，报告定位到页的起始时间，并标记待试听复核。合理数字读法、标点和口语差异不应扣分。
- 配音内容一致性不包含音色相似度、音质和完整口型评价。ASR 可能识别错误，重新配音前必须结合原音频试听判断。
- 评分扣分缺少具体问题和证据、模型返回项目与选择不符、材料在评价期间变化等情形均为评价异常，不产生新的有效通过结果，也不自动重写讲稿。
- 所选项目、通过线、评价模型、原文题库配置、语言或材料变化会使旧报告过期；重新评价可能发生新的评价模型调用，历史报告仍保留。

## 模型与费用

模型仍在「模型配置」中选择，评估项目和门槛位于独立卡片。知识问答需要不同型号的出题与答题模型；只选视觉/呈现/配音检查时，无需出题或原文题库。只选 PPT 展现无需音轨识别。

逐页检查将一页勾选的多个评价项目合并为一次评价请求，并缓存相同材料和配置的结果。抽帧方案纳入证据缓存标识，切换呈现检查不会复用缺少所需帧的缓存。逐页评价会增加评价请求；本地识别、合片和备份不产生模型 API 费用。

## 修复流程

| 问题 | 决策入口 | 重新处理的环节 |
| --- | --- | --- |
| 讲稿知识缺漏 | 根据评估优化讲稿 | 复用课件，重写讲稿，重新评价 |
| 成片知识低分 | 按知识反馈重写讲稿 | 复用课件，修订讲稿再配音合片 |
| PPT 可读性/版式问题 | 优化课件与讲稿 | 克隆原文 LaTeX 工程，将视觉问题送入课件提示词，重建课件及配套讲稿 |
| 试听确认配音差异 | 复核后重新配音 | 只强制重配存在差异/低分的页，复用其他页，更新定位再合片 |
| 遮挡/呈现问题 | 按当前设置重新合片 | 先调整任务字幕、模型或数字人开关，复用课件和音频重新合片 |

视觉、配音或呈现失败时暂停等待定向修复。只有成片知识单项失败、低于知识自动修复线且额度未用完，才沿用有限自动讲稿重写；不会把视觉或配音低分误当成讲稿问题。

修复任务使用独立产物目录，不将复制来的旧成片当成本轮新产物。局部配音修复使用稳定的修复标识避开旧页音频/分段缓存；同一次修复失败后续跑则复用已完成的新页，避免重复生成。新一轮修复使用新标识。

## 成片备份

完整合片完成、评价完成、修改已有成片的讲稿之前，以及每次修复/重跑之前，自动保存不可变快照。视频 SHA-256 校验、讲稿复制与清单写入全部成功后才发布备份；失败时停止覆盖或修复。相同视频、讲稿、配置和评价的快照去重；同一视频的评价或配置变化会保留不同快照。

备份位于 `jobs/{所属任务}/video_versions/{时间戳-随机编号}/`，包含 `video.mp4`、可用时的 `script.txt`、以及记录配置、评价、来源任务、时间、原因和哈希的 `manifest.json`。续跑与修复任务沿用所属任务的备份集合，任务详情的「成片版本备份」可下载视频、评价与配置、讲稿，视频下载支持 Range。

备份不会自动清理，会持续占用磁盘。已有历史任务在下一次修改或修复前保存仍可读取的成片；已被早先流程覆盖的文件无法从本次改造恢复。

## 离线验证

`scripts/check_selective_evaluation.py` 覆盖项目/门槛校验、独立分流、真实小视频逐页证据提取、评价缓存、材料变更拒绝、三种修复隔离、本地及云配音定向重配与恢复、备份失败停止、不可变版本、Range 下载和人工继续防重复。模型及 ASR 使用替身，不产生付费请求。

既有问答、合片时间轴、配音适配器、续跑与前端配置回归继续通过。浏览器在隔离虚构任务上验证项目切换、阈值刷新恢复、结果证据、备份入口、确认/取消、修复载荷及明暗/窄屏布局；实际本机服务进行只读能力与路由检查。
