# 讲稿角色、模型选择与并发进度修复

## 任务与成果

- 用户反馈中文授课推荐无反馈、不能选模型、讲稿描述幻灯片、剩余时间与卡住判断失真，希望并发生成讲稿。
- 中文推荐按 zh/zh 查找实际预设，已是中文时明确提示；自定义提示词仍保留，变化后的教案需重新确认。
- 本机同源 POST /api/models 读取用户所填兼容接口模型列表。自动读取、手动刷新、搜索下拉与手动模型 ID 均可用。文字模型、讲稿/视觉模型、1～8 并发保存到新任务；任务审核重写使用任务模型。
- 所有五种内容类型的中英文讲稿模板重写为符合角色的内容讲解；课程直接教概念、原因、例子和推导，禁止讲页码、版式、标题作为主体。相邻课件文字提供稳定衔接，课程另含源材料和时长预算。
- 所有类型逐页并发生成，默认 3，标准库线程池；完成顺序可乱序，输出仍按页序。逐页缓存和失败恢复保留成功结果，其他页不覆盖。配音与本机 GPU 工作仍串行。
- 旧 110 秒是整批讲稿阶段固定估计，不是单页估计，已经移除。现在按实际新生成页速度动态计算，首个结果前不显示剩余。每页更新计数和活跃时间，旧任务兼容解析讲稿保存日志，避免将持续生成误判为卡住。
- 兼容接口根据任务模型和地址路由；未知模型不强制 65536 输出上限。结构化与课件缓存包含服务地址和模型，版本升到 3；旧文件不删除。
- 重写可选择最新类型模板，新任务保存新快照，原任务模板和真实已有讲稿不自动修改。

## 遇到的问题与后续注意

- 原生 datalist 在内嵌浏览器候选展示不稳定，改用已有 TDesign Select，无新增依赖。Select ref 返回组件实例，不能直接 querySelector；标签绑定改为普通 DOM 容器引用，实际可按字段名定位输入。
- 下拉浮层会沿用桌面宽度；限制浮层及内容最大宽度后复验窄屏通过。
- 429/401 测试发现 PIL 图片未关闭会在 Windows 临时目录清理时报 WinError 32；现以 with 打开并复制图片，释放文件句柄。
- 服务商模型列表不标注视觉能力。必须选支持图像输入的讲稿模型；列表不可用可手动输入。并发吞吐受限流影响，默认 3 不承诺三倍速度，遇限流可降到 1。
- 尚未进行真实长课程付费推理、40 分钟配音标定与教师风格质量评审。模板改善与预算不是成片精确时长保证，已有错误讲稿需要用户从审核界面明确重写。
- 重载网页后浏览器文件对象不可恢复，需要重新选原文件；草稿文字、音色和模型已保留。
